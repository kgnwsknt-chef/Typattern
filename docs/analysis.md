# 分析（n-gram）

打鍵の間隔を、続けて押したキーの組（n-gram）ごとに分析する決まり。計測の決まりは `docs/measurement.md`、絞り込みは `docs/records.md`。ルールを変えるときは、このファイルとコードを一緒に直す。

## bigram・trigram

n-gram のページ（`ngram.html`）に、続けて押した2キー（bigram）・3キー（trigram）ごとの平均 IKI（打鍵間隔）と出現回数を一覧で表示する。実装は `js/ngram.js`。タイピング終了時の結果画面には出さない。

- **元のデータ**：生データの events の `"k"` の行（押した物理キーと時刻。`docs/storage.md`）を、記録された順に並べたもの。英語も日本語も同じ。日本語ではかなではなく、押したキーの組になる。
- **表示**：キーの番号を、US の QWERTY でそのキーに割り当てられた文字（Shift なし、小文字）で表す（例 `21` → `a`、`38` → `,`）。`keyLayout` によらず QWERTY の文字で表す。
- **bigram の IKI**：「ab」の IKI は、a のキーを押してから b のキーを押すまでの時間。
- **trigram の IKI**：「abc」の IKI は、a→b と b→c の2つの間隔の平均（= a から c までの時間 ÷ 2）。1打あたりの値なので、bigram と同じ尺度で比べられる。
- **例**：英語の `point` → bigram `po` `oi` `in` `nt`、trigram `poi` `oin` `int`。日本語の「しか」を `shika` と打つと → bigram `sh` `hi` `ik` `ka`、trigram `shi` `hik` `ika`
- **Shift は並びに入れない**：Shift のキーそのものは n-gram の1キーとして数えない。
- **除くもの**：次のキーが1つでも含まれる組は数えない。
  - 間違えたキー（判定 `0`）と Backspace。打ち直しの間隔は、キーからキーへの動きではないため。間違えた後に Backspace で直して打ち直したキーは、その次のキーとの組からは数える。
  - Shift と同時に押したキー（Shift を押してから離すまでの間に押したキー。大文字や記号）。Shift を離したことは events の `"u"` の行で分かる。
  - スペースのキー（英語は単語の中だけを数える）。句読点のキー（`s,` `e.` など）は数える。
- 英語と日本語の記録をまとめて選ぶと（言語の絞り込みが「すべて」）、同じキーの組はまとめて数える（英語の `ka` とローマ字の `ka` は同じ）。
- **平均 IKI**：同じ n-gram の IKI の平均（ms、整数に丸めて表示）。色は「キーごとの間隔」と同じ配色で、全体の平均間隔を基準にする。
- **SD**：同じ n-gram の IKI の標準偏差（標本標準偏差。n-1 で割る。ms、整数に丸めて表示）。ばらつきが大きいほど、打つたびに速さが安定していない。1回しか出ないものは `-`。trigram は1回ごとの値（2つの間隔の平均）のばらつき。
- **分布**：表の上（bigram は左、trigram は右）に、選んだ n-gram の IKI の分布をヒストグラムでいつも表示する。最初（と、表示中の n-gram が絞り込みで表から外れたとき）は、平均 IKI が一番小さいもの（同じなら回数の多いもの）を出す。行をクリック（または Enter）するとその n-gram に切り替え、ページを分布が見えるところまでスクロールする。横軸は 0〜最大（設定のページで変えられる。初期値 2000 ms、`docs/settings.md`）で、100 個の区間に分ける（区間の幅 = 最大 ÷ 100。初期値なら 20 ms）。目盛りは切りのよい間隔で6本程度。最大以上の値は一番右の区間に入れ、1回ごとの線や平均の点線も右端に描く。平均を黒の点線、1回ごとの値を横軸の下の短い線で示す。棒の色は表と同じ配色。同じ行をもう一度クリックしても閉じない（閉じるボタンもない）。
- **並び順**：n-gram（文字）・平均 IKI・回数の見出しをクリックすると、その列で並べ替える。初期値は平均 IKI の昇順（速い順）。別の列を選んだときは、n-gram は文字の順、平均 IKI は速い順、回数は多い順から始め、同じ列をもう一度クリックすると昇順と降順が切り替わる。並べ替えに使っている列の見出しは青く、▲（昇順）か ▼（降順）を付ける。同じ値のときは、回数の多い順 → 速い順 → 文字の順。文字の順は文字コードの順（記号 → 数字 → 英字）。並び順は表ごとに持ち、絞り込みを変えても維持する。
- 1回しか出ないものも表示する。

## n-gram のページ

n-gram のページ（`ngram.html`）で、保存した記録をまとめて bigram・trigram を集計する。実装は `js/ngram-page.js`（集計の元になる計算は `js/ngram.js`）。

- **並び**：上から、データの絞り込み → 「回数」（N 回以上）・集計の行（総打鍵数・種類・打鍵間隔の平均）・説明 → bigram の2次元ヒストグラム → クリックで出る分布（左が bigram、右が trigram）→ bigram・trigram の表（左右に並べる）。

- **集計のしかた**：選んだ記録それぞれの生データ（events の `"k"`・`"u"` の行）から、上記のルールで n-gram の IKI を出し、すべて足し合わせて平均する。
- **絞り込み**：ページ上部の「データの絞り込み」（`docs/records.md`）で選んだ記録を使う。
- **データがないとき**：表は見出しだけを出し、中に「データなし」と表示する。
- **回数**：「N 回以上」で、出現回数が少ないもの（値がぶれやすい）を隠せる。
- **総打鍵数**：表の上の集計の行の初めに「総打鍵数 1,499」のように出す。選んだ記録で押したキー（生データの events の `"k"` の行）の数で、Shift・Backspace・間違えたキー・スペースも数える（n-gram から除くキーも含む）。
- **色の基準**：選んだ記録の、n-gram に使えるキーの間隔（bigram の1回ごとの値）すべての平均。
- **並び順**：上と同じ（初期値は IKI の昇順、見出しのクリックで列と向きを切り替え）。

## bigram の2次元ヒストグラム

n-gram のページの、集計の説明と表の間に、bigram を2次元のヒストグラム（マスの色で値を表す図。ヒートマップ）で2枚表示する。実装は `js/ngram.js` の `drawHeatmap`。

- **軸**：横軸 = 1キー目、縦軸 = 2キー目。キーは QWERTY の文字で書く。選んだ記録の bigram に出てくるキーだけを、キーボードの行の順（数字の行 → Q の行 → A の行 → Z の行。行の中は左から）に並べる。行が変わるところに区切り線を入れる。
- **対象**：上の bigram の表と同じ（除外の決まり、「回数」の「N 回以上」も同じ）。足りないマスは空にする。
- **回数**：マスの色の濃さで出現回数を表す。0 回は白、一番多いマスが一番濃く、その間は回数に比例する。
- **平均 IKI**：マスの色は表と同じ配色（速い = 青、全体の平均 = 緑、平均の2倍以上 = 赤）。基準は表と同じ「色の基準」。データのないマスは白（回数の図の 0 回と同じ）。
- 図の下に色の凡例を置く。マスにマウスを乗せると、bigram・回数・平均 IKI を表示する。
- **分布**：データのあるマスをクリック（または Enter）すると、bigram の表でその行をクリックしたのと同じになる（表の中をその行までスクロールし、表の上にその bigram の IKI の分布を出す。ページは分布が見えるところまでスクロールする）。分布を表示中の bigram のマスは、2枚とも枠で囲む（表の行をクリックしたときも同じ）。同じマスや行をもう一度クリックしても閉じない。
