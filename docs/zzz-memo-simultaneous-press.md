# 同時押しの配列の bigram・trigram の分析（メモ）

シフトとの同時押しや、英字キー同士の同時押しでかなを打つキー配列を、IKI のページなどでどう分析するかの案。キーの同時押しには当面対応しない（`CLAUDE.md` の「今後」）ので、まだ決まりではない。対応するときに、ここから決めて、それぞれの文書（`docs/measurement.md`・`docs/storage.md`・`docs/analysis_iki.md` など）に書く。

## 案：押した順に1打ずつ並べ、「重なり」の印を付ける

前置・後置シフトと分析の仕方をそろえるための案。

- 押したキーを、押した（keydown）順に1打ずつ並べる。前置・後置シフトと同じく、かな配列のシフトのキーも1打に数える（英語の Shift は今のまま数えない。`docs/measurement.md` の「平均 IKI」）。
- bigram ごとに「重なり」（前のキーを押したまま次のキーを押したか）の印を付ける。同時押しの「ぱ」= `;` と `x` は、前置シフトの `;` → `x` と同じ bigram `;x` になり、違いは重なりの有無と IKI の短さだけになる。
- 和音の中のずれ（同時に押したキーの時刻の差）は、重なりのある bigram の IKI として見える。
- IKI のページの bigram の表と分布に「重なり：あり／なし／すべて」の絞り込みを付けると、和音の中と和音から和音へを分けて見られる。
- 集計（IKI のページ・指と行(row)の分類・ミスタイプのページ）は今の仕組みのまま使え、前置・後置シフトの配列と同じ表で比べられる。
- 重なりのある bigram はごく短いので、IKI の分布は2つの山になり、平均 IKI は小さく出る（1かなに2打なのは前置シフトも同じ）。配列どうしの速さは「かな/分」で比べる。

## 前提：離した時刻

- 重なりを見分けるには、すべてのキーの離した時刻が要る。v0.115 から、すべてのキーの離した時刻（`"u"` の行）を記録している（`docs/storage.md` の「`events`」）。それより前の記録は Shift の分だけなので、重なりは分からない。

## 割り当て表の書き方

- かな配列のキーの並びでは、キーとキーの間の `+` は同時押しを表す。`+` は前後の1キーだけを結ぶ。
  - `j+k` … j と k を同時に押す。`j+k+l` … 3つを同時に押す。
  - `j+kl` … j と k を同時に押してから l。`jk+l` … j を押してから、k と l を同時に押す。
- 同時押しのキーは押す順を問わない（`k+j` は `j+k` と同じ）。読み込むときに決まった順に並べてそろえる。
- かな配列では、Shift ＋ `=`（`+`）のキーにかなを割り当てられなくなる。英語の配列の `+` は今のまま Shift ＋ `=` のキー（英語の配列は同時押しを使わない）。
- `|` は「または」と読まれやすく、`l` と紛れるので使わない。JIS だけにあるキーの文字（`¥` など）も、`\` と見分けにくいので使わない。

## 判定の考え方

- 同時押しは、押した時刻の差ではなく、一緒に押されている瞬間があったか（重なり）で決める。最初に押したキーを離す前に残りのキーを全部押せば正解（順も時間差も問わない）。最後のキーを押した瞬間に確定する。
- 全部押す前にどれかを離した、書いていないキーが混ざった、ときはミス。
- 順に押す並び（`jk`）は、重なっていても順に押していれば正解（ロールオーバー）。
- `jk` と `j+k`、`j+k` と `j+k+l` が紛れるときは、今のかな配列の判定と同じくお題を手がかりにする。
- 残る問題：
  - ミスしたときに、打ったものを同時押しとみなすか（赤で上に出すかな）。重なりの長さで区切るか。
  - 重なりがごく短い同時押しを同時押しにするか（初めは区切りなしにして、記録の分布を見て決める）。
  - 同時押しのつもりで少し早く離した（重なりがない）ときに、短い時間差なら許すか（初めは許さない）。
- 3キー以上の同時押しは、キーボードによって一部のキーが届かないことがある（ロールオーバーの限界）。キー配列のページに注意書きが要る。

## ほかの案：和音を1打にする

同時に押したキーのまとまり（和音。例 `[j+k]`）を1打とし、和音の最初のキーの時刻で IKI を取り、和音の中のずれは別の表にする案。手の動きのまとまりには合うが、前置・後置シフトの配列と数え方が変わり、和音を見つける仕組みや、指と行(row)の分類の読み替えが要るので、上の案を本命にする。
