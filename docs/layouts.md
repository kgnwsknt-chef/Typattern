# キー配列

キー配列のページ（`layouts.html`）の決まり：配列図・試し打ち・割り当て表の登録（かな配列と英語の配列）。実装は `js/layouts-page.js`（ページの処理）、`js/keyboard-shapes.js`（キーボードの形）、`js/kana-layout.js`（割り当て表の読み込みと変換。かな配列も英語の配列も）、`js/keys.js`（物理キーの番号）。保存形式は `docs/storage.md`、タイピング画面での判定は `docs/measurement.md` の「英語の配列」と「日本語（ローマ字入力・かな配列）」。

- **開き方**：設定のページの「登録」の「キー配列」から開く。このページを開いている間は、一番上のリンクの「設定」を強調し、ページの上に「設定 › キー配列」の戻り道を出す。

## 配列

| 配列 | 中身 | 保存 |
| --- | --- | --- |
| QWERTY | 最初から入っている。各キーの文字は `js/keys.js` の表 | しない（コードの中にある） |
| かな配列 | 利用者が割り当て表（キーの並び → かな）を読み込んで登録する | IndexedDB の `layouts` |
| 英語の配列 | 利用者が割り当て表（キー → 文字）を読み込んで登録する。Dvorak・Colemak など、アルファベットや記号の位置を入れ替えた配列 | IndexedDB の `layouts` |

- **使えるところ**：かな配列は日本語だけ。英語の配列は、英語と、日本語のローマ字入力（押したキーを割り当て表で文字にしてからローマ字として判定する）で使える。
- かな配列・英語の配列は最初から入れず、利用者が自分の割り当て表を読み込んで登録する。配列の数も版も人によって違うため。記録には配列名を残す（どの割り当てで打った記録か分かるように）。
- 配列名は利用者が自由に付ける。版を付けるなら名前に入れる（例 `tsukimisou-v2`）。アプリは版を付けない。
- 最初から入っている配列の名前（`qwerty` と、表示する名前の「QWERTY配列」。大文字・小文字は区別しない）は使えない。
- タイピング画面の「配列」・記録ページの絞り込みでは、配列名をそのまま出す（「（かな配列）」「（英語）」などは付けない）。QWERTY は「QWERTY配列」と出す（記録の `keyLayout` は `qwerty`）。かな配列と英語の配列で同じ名前は使えない。記録はあるが登録を消した配列は「名前（削除済）」と出す。

## キーボードの形

- 配列図の外形（キーの位置と幅）。「キーボードの形」で選び、ブラウザが覚える（localStorage `typing-test.keyboardShape`）。
- 今は「ロースタッガード（US）」だけ。形は `js/keyboard-shapes.js` に e.code（押したキーの物理的な位置）と幅の並びで書き、足していける。
- 配列とは別に選ぶ（配列ごとに形は持たない）。はじめは keyboard-layout-editor の JSON を配列ごとに読み込む案だったが、物理的な形は選べるようにして、配列ごとには持たないことにした。

## 物理キーの番号


記録（`events` の `"k"` の行）と配列図に使う、物理キーの番号の決まり。対応表は `js/keys.js`。

- 番号は **2桁の「行＋列」**。行は数字の行が `0`、Q の行が `1`、A の行が `2`、Z の行が `3`、スペースの行が `4`。**列は16進数**（1 から数え、9 の次は a, b, c, d, e, f）。2桁にそろえ、`1` と `11` の読み違えを防ぐ。
- 「1」のキーを `01`、Q を `11`、A を `21`、Z を `31` とする（P は `1a`）。数字の行の左端（US の `` ` ``）は `00`。Backspace は `0d`。
- **左 Shift は `30`、右 Shift は `3c`**：左 Shift は Z（`31`）の左なので列 `0`。右 Shift は JIS では「ろ」（`3b`）の右にあるので `3c`。US キーボードには「ろ」がなく `3b` は空きになるが、右 Shift の番号は配列によらず `3c` にそろえる。
- **JIS の ¥ キー（`e.code` は `IntlYen`）は `1d`**：US 配列の Q の行の右端の `\` のキー（`1d`）に当たるので、同じ番号として読む。
- **JIS の「ろ」キー（`e.code` は `IntlRo`）は `3b`**：Z の行の `/`（`3a`）の右なので、続きの番号にする。
- **スペースは仮に `45`**：JIS の下の行の並び（Ctrl 41・Win 42・Alt 43・無変換 44・スペース 45）で数えた。
- `e.code` と1対1で対応づけ、OS の入力設定（US／JIS）に左右されないようにする。

## 配列図

- 各キーの左上に物理キーの番号（行＋列。列は16進数。上の「物理キーの番号」）。文字のないキー（Tab・Shift など）は名前を書く。
- **QWERTY**：中央に Shift なしの文字、右上に Shift ありの文字。英字は Shift ありが大文字になるだけなので右上には書かず、Shift を押している間は大文字で表示する。
- **かな配列**：中央に表示中のシフト面でそのキーを押したときのかな、右上に Shift ＋ そのキーのかな、右下にそのキーの QWERTY の文字。かながないキーは薄い灰色。
- **英語の配列**：中央にそのキーを押したときの文字、右上に Shift ＋ そのキーの文字（QWERTY と同じく、英字の大文字は書かない）、右下にそのキーの QWERTY の文字。割り当て表にないキーは、QWERTY の文字のまま（右下には書かない）。シフト面の選択は出さない。
- **シフト面**（かな配列のときだけ選べる。どのキーと組み合わせたときのかなを出すか。50音の「あ段」などと紛れないよう「段」とは呼ばない）：
  - **自動**（初期値）：試し打ちの打ちかけの並びに続けて押したときのかな。何も打ちかけていなければシフトなし。同時押しシフトのキーを押している間は、その同時押しシフト。
  - **シフトなし**：そのキーだけを押したとき。
  - **前置シフト「x」**：x の次に押したとき。**後置シフト「y」**：そのキーの次に y を押したとき。
  - **同時押しシフト「x・y」**：x か y と同時に押したとき（下の「同時押し」）。長押しシフトのキーなら **長押しシフト「x・y」** と呼び、x か y を押しながら押したとき（下の「長押しシフト」）。割り当て表のまま出すので、シフトのキーどうしの組（`d+k` など）は、そのシフトのキーの上にも出る。
  - 前置シフト・後置シフトの候補は、割り当て表の2打の並びで、1打目（前置）・2打目（後置）に5回以上出てくるキー。
  - 同時押しシフトの候補は、2キーの同時押しに5回以上出てくるキー。組む相手が5つ以上共通で、その相手とのかながどれも同じキーは、1つの同時押しシフトにまとめる。割り当ての多い順に並べる（同じならキーの文字の順）。
  - 配列図では、前置シフトのキーの外形線をオレンジ、後置シフトのキーを紫（両方に当たるキーは、オレンジの外側に紫の線）、同時押しシフトのキーを緑にする。色は `style.css` の `--kb-prefix`・`--kb-postfix`・`--kb-chord`。
  - シフト面の選択は配列図のすぐ上に置く。「自動」のときは、選択の横に今どのシフト面を出しているか（例「→「j」の次に押したとき」）を書く。打ちかけの並びだけで確定できるかながあれば「ほかのキーか Enter を押すと『っ』で確定」のように書き添える。
- **同時押し**（かな配列の `j+k` などの行。下の「同時押し」）のうち、同時押しシフトの配列図に出ないもの（シフトのキーを含まない組・3キー以上の組・`j+kl` のように順に押すキーを含む並び）は、配列図の下に「同時押し（配列図には描かない。50 ms 以内に全部押す）：」に続けて、`j+k` ぱ のようにキーの並びの順に並べる（時間は設定の判定時間）。そのような行がなければ出さない。

## 試し打ち

- 枠をクリックしてからキーを押すと、配列図のそのキーの色が変わる（押している間だけ）。キーは e.code で受け取る（JIS の ¥ キーは US の `\` の位置 `1d` が光る）。
- 枠の下に、押したキーの番号・e.code・文字を出す（割り当て表を書くときにキーの番号を確かめるのに使える）。
- **QWERTY**：打った文字を出す。Backspace で1文字消す。
- **かな配列**：割り当て表で**最長一致**の変換をして、かなを出す。
  - 続けて押したキーが表のどの並びの始まりにもならなくなったら、それまでの並びを確定する。それより長い並びがなければ、すぐ確定する。
  - 表にない並びは、打ったキーの文字のまま出す。
  - 打ちかけの並びは、点線の下線つきの薄い文字で出す（それだけで確定できるかながあれば、そのかな）。
  - Enter で打ちかけの並びを確定する。Backspace は打ちかけのキーを1つ（同時押しは組ごと）、なければ確定した文字を1つ消す。
  - 試し打ちはお題と比べない（タイピング画面の判定とは別）。
  - **同時押し**：同時押しの組に入るキーを押したら、設定の判定時間（`chordTerm`。`docs/settings.md`）のあいだ待ち、その間は打ちかけとして薄く出す。待っている間に組のキーが全部押されれば（どれも離さずに）同時押しとして並びに足す。より大きい組（`j+k` に対する `j+k+l`）がなければ、組がそろった時点ですぐ決める。時間が過ぎる・組のキーを離す・組に入らないキーを押す、のどれかで、待っていたキーを順に押したものとして足す。押し続けたときの連打は受け付けない。決まりはタイピング画面と同じ（`docs/measurement.md` の「かな配列」）。
- **英語の配列**：押したキー（Shift を押していれば Shift ＋ そのキー）を割り当て表で文字にして出す。表にないキーは、QWERTY の文字のまま出す。Backspace で1文字消す。
- IME がオンのまま打つと、オフにするよう注意を出す。Ctrl などとの組み合わせと Tab は、ブラウザの操作のまま。
- 試し打ちは記録に残さない。

## 割り当て表の登録

- 「キー配列の登録」で **種類**（かな配列／英語）を選び、配列名を入れ、ファイルを選ぶか表を貼り付けて「読み込んで表示する」を押すと、配列図・試し打ち・割り当て表の一覧で確かめられる（まだ保存しない。配列の選択肢に「（未保存）」と付き、ページを読み直すと消える）。
- 確かめたら、配列図の上の「この配列を保存する」で保存する。
  - 同じ名前の配列がすでにあれば、上書きしてよいか2回押しで確かめる。1回目でボタンの横に注意を出し、ボタンを「上書きして保存する」（赤）に変える。もう一度押すと上書きする。6秒たつか配列を選び直すと元に戻る（確認のダイアログ `confirm` は、出さないブラウザでは押せなくなるので使わない。削除も同じ）。
  - その配列で打った記録があっても上書きできる（1回目の注意で記録の件数を知らせる）。記録は残るが、記録の `keyLayout` は配列名なので、前の割り当て表で打った記録と区別できなくなる。区別したいときは別の名前（版を付けた名前など）で保存する。
- 割り当て表を直して「読み込んで表示する」を押すと、配列の選択は「配列名（未保存）」になり、「この配列を削除する」は出ない。保存済みの配列を消すときは、配列の選択で保存済みの方を選ぶ。
- 保存した配列を選ぶと「この配列を削除する」が出る。削除は2回押しで確かめる（1回目でボタンを「本当に削除する」（赤）に変え、注意を出す）。その配列で打った記録があっても削除できる（1回目の注意で記録の件数を知らせる）。記録は消さずに残り、記録ページの絞り込みでは「配列名（削除済）」と出す。
- 保存した配列は、記録の書き出し・読み込みにも入る（`docs/storage.md`）。
- かな配列・英語の配列を表示したとき（読み込んだとき・保存した配列を選んだとき）は、その種類・配列名・割り当て表を登録のフォームに出す。割り当て表は読み込んだときの文字列のまま（ローマ字で書いたならローマ字）。直して「読み込んで表示する」を押せば、読み込み直せる。QWERTY を選んだときは、種類を英語、配列名を「QWERTY配列」にして、各キーがそのキーの文字を出す割り当て表（英字の大文字とスペースは書かない）を出す（英語の配列を作るときのひな形にも使える。この名前のまま読み込んだときは「この配列を保存する」を押せない）。

### 割り当て表の書き方

割り当ては「キーの並び → かな」の表で書く。前置シフト・後置シフト・3打以上の並びも、すべて1行で表せるため。ほかのツールの表（`{"キー", "かな"},` の形）も、そのまま貼り付けて使えるようにしている。

1行に1つ。空の行と、`#` か `//` で始まる行は読み飛ばす。同じキーの並びが2回出てきたら、後の行を使う。

| 形 | 例 |
| --- | --- |
| 波かっこと二重引用符 | `{"j'", "pi"},`（行末のカンマはあってもなくてもよい。`\"` と `\\` が使える） |
| 空白区切り | `j' pi`、`t`［タブ］［タブ］`wo`、`te we`（区切りはタブ・半角スペース・全角スペースで、いくつ続いてもよい） |

- **キーの並び**：US キーボードの QWERTY の文字で書く。Shift ありの文字（大文字・記号）は Shift ＋ そのキー。
- **かな**：かなで書くか、ローマ字で書く（例 `j xtu`）。英数字と記号だけならローマ字とみなし、ふつうのローマ字入力の決まりでかなに直す（`js/romaji.js` の `toKana`）。
  - 長く一致する書き方を先に使う（`pya` → ぴゃ）。
  - `n` の次が母音・y・n・`'` でなければ「ん」。同じ子音が2つ続いたら前の1つは「っ」。
  - 記号：`-` → ー、`,` → 、、`.` → 。、`/` → ・、`[` → 「、`]` → 」、`~` → 〜。
  - 割り当て表でよく使われる `txu` も「っ」と読む（タイピング画面のローマ字の判定では受け付けない）。
  - 保存する表は、どちらで書いてもかなにそろう。
- 読めなかった行は、行番号・行の中身・理由（キーの並びとかなに分けられない、かなに直せない、`+` の書き方が違う）を一覧で出す。

#### 同時押し

- かな配列のキーの並びでは、キーとキーの間の `+` は同時押しを表す。`+` は前後の1キーだけを結ぶ。
  - `j+k` … j と k を同時に押す。`j+k+l` … 3つを同時に押す。
  - `j+kl` … j と k を同時に押してから l。`jk+l` … j を押してから、k と l を同時に押す。
- 同時押しのキーは押す順を問わない（`k+j` は `j+k` と同じ）。読み込むときに文字の順に並べてそろえる。
- かな配列では、Shift ＋ `=`（`+`）のキーにかなを割り当てられない（`+` だけの行は読めなかった行にする）。`+` で始まる・終わる、`++` を含む、同時押しの中に同じキーが2回ある行も、読めなかった行にする。英語の配列の `+` は今のまま Shift ＋ `=` のキー（英語の配列は同時押しを使わない）。
- 同時押しかどうかの決まりは `docs/measurement.md` の「かな配列」。組のキーの数に上限は設けない。3キー以上の同時押しは、キーボードによっては一部のキーが届かないことがある（同時に押せるキーの数の限界）。
- 同時押しのあるかな配列は、キー配列習得には使えない（`docs/layout-learning.md`）。

#### 長押しシフト

- 割り当て表に `shift d k` のような行を1行書くと、そのキーが長押しシフトのキーになる。シフトのキーはスペースで区切り、1文字ずつ書く。この形の行（最初の語が `shift`）は、ふつうの割り当ての行としては読まない。
- 割り当ての行は同時押しと同じく `d+j` と書く。`d` を押しながら `j` を押したときのかなになる。どのキーがどのシフト面になるかは、この行で決まる（左右どちらのシフトでも打てるようにするなら `d+j` と `k+j` の両方を書く）。
- シフトのキーの単独の行（`d` だけの行）があれば、単独で押して離したときのかな。なければシフト専用のキーになる。
- シフトのキーを含まない `+` の行は、上の「同時押し」のまま。
- 見分け方の決まりは `docs/measurement.md` の「長押しシフト」。試し打ちも同じ決まり（決まるまでは打ちかけとして薄く出す）。
- 長押しシフトのあるかな配列は、キー配列習得には使えない（`docs/layout-learning.md`）。

#### 英語の配列

書き方（2つの形・読み飛ばす行・後の行を使う）は、かな配列と同じ。例（Dvorak の一部）：`q '`、`w ,`、`s o`、`{"Q", "\""},`。

- **1キー → 1文字**：キーの欄は QWERTY の1文字（Shift ありの文字は Shift ＋ そのキー）、文字の欄は1文字だけ。英語では2打で1文字になる配列はまずないため。2文字以上の行は、理由付きで読めなかった行にする。
- **文字はそのまま**：かな配列のようにローマ字をかなに直すことはしない。
- **英字の大文字は自動で作る**：英字のキー（`a`〜`z`）が英字を出す行（例 `s o`）があって、そのキーの大文字の行（`S`）がなければ、大文字どうしの行（`S O`）を足す。英字以外を出すキー（例 `q '`）や記号のキーの Shift 面は、書いた行だけを使う。
- 表にないキーは、QWERTY のときと同じ文字を出す（数字やスペースなど、入れ替えないキーは書かなくてよい）。

## まだ決まっていないこと

- **物理キーの番号の細部**：スペース（仮に `45`）の番号の確定。ほかの行の列 `0` を使うか（Tab・Caps Lock など）。JIS だけにあるキーのうち ¥・ろ 以外（変換・無変換など）の番号。JIS キーボードの `]` のキー（`e.code` は `Backslash`）と ¥ が、どちらも `1d` になる問題。
- **キーボードの形**：ロースタッガードの US 配列のほかに、どの形を足すか（JIS、オーソリニアなど）。keyboard-layout-editor の JSON を読み込めるようにするか。
