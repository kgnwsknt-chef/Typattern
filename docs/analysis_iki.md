# IKI の分析（キーごと・n-gram）

打鍵の間隔を、キーごとと、続けて押したキーの組（n-gram）ごとに分析し、IKI のページ（`analysis_iki.html`）に出す決まり。計測の決まりは `docs/measurement.md`、絞り込みは `docs/records.md`。ルールを変えるときは、このファイルとコードを一緒に直す。

## IKI のページ

IKI のページ（`analysis_iki.html`）で、保存した記録をまとめて bigram・trigram を集計する。実装は `js/ngram-page.js`（集計の元になる計算は `js/ngram.js`）。

- **並び**：上から、データの絞り込み → 「回数」（N 回以上）・集計の行（総打鍵数・種類・打鍵間隔の平均）・説明 → キーごとの IKI（配列図）→ bigram の2次元ヒストグラム → 「推移の横軸」の選択 → クリックで出る分布とその下の推移（左が bigram、右が trigram）→ bigram・trigram の表（左右に並べる）→ 指と行(row)で分けた bigram・trigram（一番下。2次元ヒストグラムと、そのマスをクリックして出る bigram の分布を離さないため）。

- **集計のしかた**：選んだ記録それぞれの生データ（events の `"k"`・`"u"` の行）から、下の「bigram・trigram」のルールで n-gram の IKI を出し、すべて足し合わせて平均する。
- **絞り込み**：ページ上部の「データの絞り込み」（`docs/records.md`）で選んだ記録を使う。練習モードの回も入る。除くときは「モード」で「練習モード以外」を選ぶ（`docs/practice.md`）。IKI 測定の回だけを除くときは「IKI 測定以外」を選ぶ。IKI 測定の回は、各語の5回のうち1回目を打ったキーが絡む組を数えない（`docs/iki-measurement.md` の「1回目を数えない」）。
- **データがないとき**：表は見出しだけを出し、中に「データなし」と表示する。
- **回数**：「N 回以上」で、出現回数が少ないもの（値がぶれやすい）を隠せる。
- **総打鍵数**：表の上の集計の行の初めに「総打鍵数 1,499」のように出す。選んだ記録で押したキー（生データの events の `"k"` の行）の数で、Shift・Backspace・間違えたキー・スペースも数える（n-gram から除くキーも含む）。
- **色の基準**：選んだ記録の、n-gram に使えるキーの間隔（bigram の1回ごとの値）すべての平均。
- **並び順**：下の「bigram・trigram」の「並び順」と同じ（初期値は IKI の昇順、見出しのクリックで列と向きを切り替え）。

## キーごとの IKI

IKI のページの、集計の説明と2次元ヒストグラムの間に、キーごとの IKI を配列図に色で示す。実装は `js/ngram-page.js` の `drawKeyIki`、配列図の描き方は `js/key-map.js`（ミスタイプのページと同じ）。

- **値**：そのキーを押すまでの間隔（直前のキーからそのキーまで）の平均（ms、整数に丸める）。bigram の2キー目がそのキーである間隔をすべて足して平均したもの。そのため、間違えたキー・Backspace・スペース・Shift と同時に押したキーが絡む間隔は除く（bigram と同じ）。
- 「回数」の絞り込みは使わず、選んだ記録のすべての bigram から出す。
- **色**：表と同じ配色（全体の打鍵間隔の平均が基準。速いほど青、平均で緑、平均の2倍以上で赤）。間隔が1回でもあれば色を付ける（回数が少ないキーは平均がぶれやすいので、マウスを乗せて回数を確かめる）。
- **配列図**：キー配列のページと同じ形で、各キーの左上に物理キーの番号、右上に QWERTY の文字、右下に値。絞り込みの「配列」でかな配列を選んでいるときは、キーの真ん中にそのキーだけを押したときのかなを書き、前置・後置シフトのキーを外形線の色で示す。英語の配列を選んでいるときは、キーの真ん中にそのキーの文字（Shift なし）を書く。マウスを乗せると平均と間隔の数を出す。

## bigram の2次元ヒストグラム

IKI のページの、集計の説明と表の間に、bigram を2次元のヒストグラム（マスの色で値を表す図。ヒートマップ）で2枚表示する。実装は `js/ngram.js` の `drawHeatmap`。

- **軸**：横軸 = 1キー目、縦軸 = 2キー目。キーは QWERTY の文字で書く。選んだ記録の bigram に出てくるキーだけを、キーボードの行の順（数字の行 → Q の行 → A の行 → Z の行。行の中は左から）に並べる。行が変わるところに黒い実線の区切り線を入れ、同じ行の中で左手と右手の担当が変わるところ（ふつうの指の割り当てで、5・T・G・B までが左手。その右から右手）に黒い点線を入れる（ミスタイプのページの2次元ヒストグラムも同じ）。
- **対象**：bigram の表（下の「bigram・trigram」）と同じ（除外の決まり、「回数」の「N 回以上」も同じ）。足りないマスは空にする。
- **回数**：マスの色の濃さで出現回数を表す。0 回は白、一番多いマスが一番濃く、その間は回数に比例する。
- **平均 IKI**：マスの色は表と同じ配色（速い = 青、全体の平均 = 緑、平均の2倍以上 = 赤）。基準は表と同じ「色の基準」。データのないマスは白（回数の図の 0 回と同じ）。
- 図の下に色の凡例を置く。マスにマウスを乗せると、bigram・回数・平均 IKI を表示する。
- **分布**：データのあるマスをクリック（または Enter）すると、bigram の表でその行をクリックしたのと同じになる（表の中をその行までスクロールし、表の上にその bigram の IKI の分布を出す。ページは分布が見えるところまでスクロールする）。分布を表示中の bigram のマスは、2枚とも枠で囲み、横軸の1キー目と縦軸の2キー目のラベルを、青い四角の上に白い太字で出して強調する（「'」「,」のような小さい記号でも場所が分かるように）（表の行をクリックしたときも、最初に一番速いものを出したときも同じ）。同じマスや行をもう一度クリックしても閉じない。
- **キーで動かす**：マスにフォーカスがあるとき（クリックした後、または Tab で図に入ったとき）、W A S D で隣のマスに動かせる（押したキーの位置 `e.code` で受け取るので、OS の入力設定によらない）。W・S は縦（2キー目）、A・D は横（1キー目）に1マスずつ動く（例 `qq` で S を押すと `qw`）。矢印キーはブラウザのスクロールに使うので割り当てない。
  - 動いた先にデータがあれば、クリックしたのと同じく分布を出す。ただし、ページはスクロールしない（表の中だけ、その行までスクロールする）。図を見ながら続けて動かせるようにするため。
  - データのないマス（白）にも止まる。そのときは表の選択を外し、分布を消す。止まっているマスは点線の枠で囲む。
  - 端まで来たら、反対の端に回る（一番下で S を押すと一番上へ）。
  - Tab で図に入れるのは1マスだけ（分布を出している bigram のマス。なければ前に W A S D で止まったマス）。実装は `js/ngram.js` の `drawHeatmap`。

## 指と行(row)で分けた bigram・trigram

IKI のページの一番下（bigram・trigram の表の下）に、押したキーを手・指・行に直し、bigram・trigram を形で分けた表を出す。キー配列を比べるときに広く使われる分け方（SFB・roll・scissors・LSB・alternate・onehand・redirect・SFS など）に合わせ、一般的な名前がないものは日本語の名前を付ける。分類は `js/finger-map.js`、表は `js/ngram-page.js`。

### 指の割り当て

- 設定の「指の割り当て」（`fingerMap`。`docs/settings.md`）を使う。初期値は、ふつうのタッチタイピングの割り当て。
  - 左手：小指 `q a z`、薬指 `w s x`、中指 `e d c`、人差し指 `r t f g v b`
  - 右手：人差し指 `y u h j n m`、中指 `i k ,`、薬指 `o l .`、小指 `p [ ] \ ; ' /`
  - 行ごとに違う指で打つとき（例：`p` を薬指で打つ）も、キーごとに指を決められる。
- **分ける範囲**：指を割り当てたキーだけ。割り当てていないキー（初期値では数字キーの行。人によって打つ指がよく違うため）・スペースなどを含む組は「分類しない」にまとめる。数字キーの行のキーも、割り当てれば分類に入る。
- **ホームの列**：各指に割り当てたホーム行のキーの列。2つ以上あるときは、人差し指は外側の端（初期値なら `f`・`j`）、小指は内側の端（`;`）、中指・薬指は真ん中（2つなら内側）。ホーム行のキーを割り当てていない指は、ホームの列がない（その指を含む組は LSB に入れない）。
- **列**：数字キーの行の `` ` `` を 0 とし、`1`・`q`・`a`・`z` を同じ列 1 とする（`5 t g b` が 5、`6 y h n` が 6）。キーボードの行のずれは数えない。
- **指の向き**：人差し指の側を内側、小指の側を外側とする。小指 → 人差し指の向きが内向き、その逆が外向き。
- **行**：上の行が奥、下の行が手前。
- キーは記録した物理キーの位置（QWERTY の文字）で決めるので、英語・ローマ字・かな配列のどれで打った記録も同じ割り当てで分ける。

### bigram・基本（どの組もどれか1つに入る）

| 分類 | 決まり | 例（QWERTY） |
| --- | --- | --- |
| alternation（左右交互） | 左右の手が違う | `th` |
| repeat（連打） | 同じキーを続けて打つ | `ee` |
| SFB（同指異鍵） | 同じ指で別のキー。内訳：同じ行（横に動く）・1行・2行以上（数字キーの行を割り当てると3行もある） | `fg`・`ed`・`ec` |
| roll（ロール） | 同じ手の別の指。内訳：内向き・外向き | `sd`・`ds` |
| 分類しない | 分ける範囲の外のキーを含む | |

### bigram・特徴（同じ手・別の指の組だけ。同じ組がいくつもの行に入ってよい）

| 分類 | 決まり | 例 |
| --- | --- | --- |
| 行(row)違い | 行が違う。内訳：内側の指が奥・外側の指が奥。それぞれを指の組（人差し指と中指・人差し指と薬指・人差し指と小指・中指と薬指・中指と小指・薬指と小指）ごとにも分ける | `rd`・`se`（内側の指が奥）、`ko`・`in`（外側の指が奥） |
| scissors | 隣の指で、短い方の指が奥の行（短い方は、人差し指と中指では人差し指、中指と薬指では薬指、薬指と小指では小指）。内訳：HSB（half scissor bigram。1行）・FSB（full scissor bigram。2行）。数字キーの行を割り当てたときの3行は数えない | `dr`・`ko`・`pl`（HSB）、`cr`（FSB） |
| LSB（横の伸ばし） | lateral stretch bigram。隣の指で、2つのキーの列の離れ方が、2つの指のホームの列の離れ方より大きい。内訳：人差し指と中指・中指と薬指・薬指と小指（初期値の割り当てでは、人差し指が中央の列 `t g b`・`y h n` を打つ組と、小指が外側の列 `[ ] \ '` を打つ組。中指と薬指の組は入らない） | `te`・`gd`、`l'` |
| 分類しない | 基本の分類と同じ | |

- 行(row)違いは、良い・悪いの判断を含まない分け方にする（内側・外側で分け、指の長さでは分けない）。どちらの向きが速いかは、測った IKI で見る。
- 横の伸ばしは、資料によってはキーの間の横の距離で決めるが、ここでは列で決める（今の配列図の形では、ほぼ同じ組になる）。割り当てを変えて、指がホームの列の外のキーを打つ（例：`p` を薬指で打つと、`pk` は中指と薬指の LSB）と、それに合わせて入る組が変わる。

### trigram・基本（どの組もどれか1つに入る）

| 分類 | 決まり | 例 |
| --- | --- | --- |
| alternate（交互） | 左右左・右左右。内訳：1・3キー目が同じ指（別のキー）・1・3キー目が同じキー | `ake`・`pen`、`dke`、`dkd` |
| roll（ロール） | 同じ手の別の指で2キー ＋ もう片方の手で1キー。内訳：内向き・外向き（同じ手の2キーの向き） | `sdk`・`kds` |
| onehand（一方向） | 同じ手の別の指で3キー、同じ向き。内訳：内向き・外向き | `asd`・`dsa` |
| redirect（向きが変わる） | 同じ手の別の指で3キー、途中で向きが変わる。内訳：人差し指を含まない | `era`・`rse`、`ads`・`sea` |
| その他 | 上のどれでもない（同じ手の中に同じ指・同じキーを含むなど） | `ter`・`ded` |
| 分類しない | 分ける範囲の外のキーを含む | |

### trigram・特徴

| 分類 | 決まり | 例 |
| --- | --- | --- |
| SFS（同じ指・別のキー） | same-finger skipgram。1キー目と3キー目が同じ指の別のキー（間のキーはどちらの手でもよい） | `dke`・`ter` |
| SFS（同じキー） | 1キー目と3キー目が同じキー | `dkd`・`ded` |
| 分類しない | 基本の分類と同じ | |

### 表

- 左に表（bigram・基本、bigram・特徴、その下に trigram・基本、trigram・特徴）、右にクリックした分類の IKI の分布（画面が狭いときは表の上）。
- **列**：分類・回数・割合・種類・IKI（ms/打）・SD（ms）・多い組。
  - **回数**：その分類に入った組を打った回数（1回打つごとに1）。
  - **割合**：全部の bigram（trigram）を打った回数に対する割合。基本の表は、字下げしていない行の合計が 100%。
  - **種類**：その分類に入った組の数。
  - **IKI**：その分類に入った組の、1回ごとの値の平均（bigram の表の IKI と同じ値の平均。trigram は2つの間隔の平均）。色は bigram の表と同じ基準。
  - **多い組**：その分類で回数の多い組（3つまで）。
- 字下げした行は、すぐ上の行の内訳。分類の名前にマウスを乗せると、定義と例を出す。
- **集計の元**：bigram・trigram の表と同じ（絞り込み・間違えたキーなどの除外・IKI 測定の1回目の除外）。ただし「回数」（N 回以上）では絞らない（少ない組も分類に入れる）。
- **分布**：回数のある行をクリック（または Enter）すると、その分類の IKI の分布を出す（描き方は bigram・trigram の分布と同じ）。推移は出さない（分類は多くの組をまとめたもので、回ごとの変化は個々の bigram・trigram の推移で見るため）。初めは、基本の表の最初の行（alternation・alternate）を出す。

## IKI の推移

IKI のページで分布を出している bigram・trigram について、その IKI が回を重ねるとどう変わったかを、分布のすぐ下に描く（bigram は左、trigram は右）。選ぶ n-gram を変えると、分布と一緒に切り替わる。実装は `js/ngram.js` の `drawTrend`（どの回の値かは `accumulate` で値ごとに覚える）。図の描き方は `js/point-trend.js`（ミスタイプのページのキーのミス率の推移と共通）。

- **縦軸**：IKI（ms）。0 から、描く点の最大（の 1.05 倍）まで。ただし設定の「分布の横軸の最大」（初期値 2000 ms。`docs/settings.md`）で頭打ちにし、それより大きい点は上端に描く。
- **横軸**：分布の上の「推移の横軸」で選ぶ（bigram・trigram 共通。初期値は回数。選び直すと、集計し直さずに推移だけを描き直す）。
  - **回数**：絞り込んだ全部の記録の古い順の通し番号（1, 2, 3 …。記録のページの推移と同じ数え方）。1回の記録の中のその n-gram の IKI を平均して1点にする。その n-gram が出なかった回は点がなく、間があく。
  - **日付**：このPCの日付で、その日の出現をすべて平均して1点にする。横軸は絞り込んだ最初の記録の日から最後の記録の日までで、打たなかった日は間があく。目盛りは最初と最後の日（間が4日以上なら真ん中も）。
- **点**：1回（1日）の平均（青）。出現が1〜2回だけの回はぶれやすいので、直近 10 点の移動平均を線（薄い紺。記録のページの推移の移動平均と同じ色）で重ねる。移動平均は、その点までの直近 10 点（10 点に満たないうちはあるだけ）の点の値の平均。
- 点にマウスを乗せると、回数なら「2 回目（2026/10/18 17:20）：平均 179 ms（2 回）」、日付なら「2026/10/18：平均 110 ms（82 回）」のように出す。
- 見出しの横に、出現した回（日）の数と、点・線の意味を書く。
- 「回数」（N 回以上）の絞り込みは、表に出す n-gram（選べる n-gram）を決めるだけに使い、推移の点は選んだ n-gram の全部の出現から出す。

## bigram・trigram

IKI のページ（`analysis_iki.html`）に、続けて押した2キー（bigram）・3キー（trigram）ごとの平均 IKI（打鍵間隔）と出現回数を一覧で表示する。実装は `js/ngram.js`。タイピング終了時の結果画面には出さない。

- **元のデータ**：生データの events の `"k"` の行（押した物理キーと時刻。`docs/storage.md`）を、記録された順に並べたもの。英語も日本語も同じ。日本語ではかなではなく、押したキーの組になる。
- **表示**：キーの番号を、US の QWERTY でそのキーに割り当てられた文字（Shift なし、小文字）で表す（例 `21` → `a`、`38` → `,`）。`keyLayout` によらず QWERTY の文字で表す。
- **bigram の IKI**：「ab」の IKI は、a のキーを押してから b のキーを押すまでの時間。
- **trigram の IKI**：「abc」の IKI は、a→b と b→c の2つの間隔の平均（= a から c までの時間 ÷ 2）。1打あたりの値なので、bigram と同じ尺度で比べられる。
- **例**：英語の `point` → bigram `po` `oi` `in` `nt`、trigram `poi` `oin` `int`。日本語の「しか」を `shika` と打つと → bigram `sh` `hi` `ik` `ka`、trigram `shi` `hik` `ika`
- **Shift は並びに入れない**：Shift のキーそのものは n-gram の1キーとして数えない。
- **除くもの**：次のキーが1つでも含まれる組は数えない。
  - 間違えたキー（判定 `0`）と Backspace。打ち直しの間隔は、キーからキーへの動きではないため。間違えた後に Backspace で直して打ち直したキーは、その次のキーとの組からは数える。
  - Shift と同時に押したキー（Shift を押してから離すまでの間に押したキー。大文字や記号）。Shift を離したことは events の `"u"` の行で分かる。
  - スペースのキー（英語は単語の中だけを数える）。句読点のキー（`s,` `e.` など）は数える。
- 英語と日本語の記録をまとめて選ぶと（言語の絞り込みが「すべて」）、同じキーの組はまとめて数える（英語の `ka` とローマ字の `ka` は同じ）。言語・配列ごとに分けて比べ、差のある bigram を並べた一覧は、苦手な単語のページに出す（`docs/weak-words.md` の「言語・配列で差のある bigram」）。
- **平均 IKI**：同じ n-gram の IKI の平均（ms、整数に丸めて表示）。色は「キーごとの間隔」と同じ配色で、全体の平均間隔を基準にする。
- **SD**：同じ n-gram の、1回ごとの IKI（上の「bigram の IKI」「trigram の IKI」で求めた値）の標準偏差（標本標準偏差。n-1 で割る。ms、整数に丸めて表示）。ばらつきが大きいほど、打つたびに速さが安定していない。1回しか出ないものは `-`。
- **分布**：表の上（bigram は左、trigram は右）に、選んだ n-gram の IKI の分布をヒストグラムでいつも表示する。最初（と、表示中の n-gram が絞り込みで表から外れたとき）は、平均 IKI が一番小さいもの（同じなら回数の多いもの）を出す。行をクリック（または Enter）するとその n-gram に切り替え、ページを分布が見えるところまでスクロールする。横軸は 0〜最大（設定のページで変えられる。初期値 2000 ms、`docs/settings.md`）で、100 個の区間に分ける（区間の幅 = 最大 ÷ 100。初期値なら 20 ms）。目盛りは切りのよい間隔で6本程度。最大以上の値は一番右の区間に入れ、1回ごとの線や平均の点線も右端に描く。平均を黒の点線、1回ごとの値を横軸の下の短い線で示す。棒の色は表と同じ配色。同じ行をもう一度クリックしても閉じない（閉じるボタンもない）。分布の下には、同じ n-gram の IKI の推移を出す（上の「IKI の推移」）。
- **並び順**：n-gram（文字）・平均 IKI・回数の見出しをクリックすると、その列で並べ替える。初期値は平均 IKI の昇順（速い順）。別の列を選んだときは、n-gram は文字の順、平均 IKI は速い順、回数は多い順から始め、同じ列をもう一度クリックすると昇順と降順が切り替わる。並べ替えに使っている列の見出しは青く、▲（昇順）か ▼（降順）を付ける。同じ値のときは、回数の多い順 → 速い順 → 文字の順。文字の順は文字コードの順（記号 → 数字 → 英字）。並び順は表ごとに持ち、絞り込みを変えても維持する。
- 1回しか出ないものも表示する。
