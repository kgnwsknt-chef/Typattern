# 計測ルール

お題・入力の判定・平均 IKI・WPM・正確率・ミスなど、タイピング中と結果画面の計測の決まり。実装は `js/app.js`。ルールを変えるときは、このファイルとコードを一緒に直す。記録ページ（絞り込み・推移・ランキング）は `docs/records.md`、n-gram の分析は `docs/analysis.md` を参照。

## 用語

| 用語 | 意味 |
| --- | --- |
| お題 | 打つべき英文（`texts/` の `.txt`。改行や連続した空白は1つのスペースにそろえる） |
| 入力 | 今入力欄に入っている文字列（Backspace で消した分は含まない） |
| 打鍵数 | 文字を1文字入力するたびに +1。Backspace などの削除は数えない |
| ミス | 入力した瞬間に、お題の同じ位置の文字と違っていた打鍵の数 |
| 正しい文字数 | 現在の入力のうち、お題の同じ位置の文字と一致している文字の数 |

## モードとお題

画面上部の「モード」で選ぶ。記録の `mode` に残し、ランキングや推移はモードごとに分かれる。

| モード | `mode` | お題 |
| --- | --- | --- |
| 文章 | `normal` | `texts/<言語>/<題材名>.txt` から1つ（約300文字） |
| 短い文章 | `short` | `texts/<言語>/<題材名>_short.txt` から1つ（約90文字） |
| 単語 | `words` | 単語リスト（`wordlists/<言語>/<リスト名>.txt`）の単語を、同じ語を重ねずにランダムな順に並べる。約300文字になるところで止める（次の語を足すと超えるときは、足した方と足さない方のうち300文字に近い方）。`textId` はリスト名（例 `basic1000`） |

- 「もう一度（Esc）」は同じお題でやり直す（単語モードでも同じ並び）。「次のお題」は新しいお題にする（単語モードは作り直す）。
- URL に `?short` を付けて開くと、短い文章で始まる。

## 文字の正誤

- 入力の i 文字目と、お題の i 文字目を1文字ずつ比べる。
- 完全一致のみ正解。大文字と小文字、記号、スペースも区別する。
- 判定は `isCorrect(typed, expected)` にまとめてある。日本語対応では、ここを言語ごとに差し替える。

## 計測

- **開始**：最初の1文字を入力した瞬間。
- **終了**：入力の長さがお題と同じになった瞬間。間違いが残っていても、最後の位置まで打てば終了する。
- 制限時間はない。

## 平均 IKI（結果の主な指標）

```
平均 IKI(ms) = 経過時間(ms) / (お題の文字数 - 1)
```

- お題1文字あたりにかかった時間。結果画面で一番大きく表示し、ランキングの基準にする。
- 打ち間違えた文字や Backspace にかかった時間も含む（ミスをするとその分遅くなる）。ミスなく打てば、打鍵の間隔の平均と同じ値になる。
- 1文字目は計測開始の打鍵なので、間隔の数は「文字数 - 1」。
- 結果画面では小数第1位まで表示・保存する。
- 打っている途中も画面上部に表示する（括弧で WPM）。途中の値は「経過時間 ÷（ここまでに進んだ文字数 − 1）」で、整数に丸める。最後まで打つと結果の値と同じになる。経過2秒未満の間は `-`。
- 「キーごとの間隔」のグラフや n-gram で使う間隔（各文字の最後の打鍵の間隔）とは別のもの（下記）。

## 未修正の間違い

- 終了した時点で、お題と違ったまま残っている文字の数。
- 間違えた打鍵はその時点でミスとして数えているので、正確率にはすでに反映されている。結果画面では「ミス（未修正 N）」と表示する。

## WPM（括弧で表示）

```
WPM = (正しい文字数 / 5) / (経過秒数 / 60)
```

- 結果画面では平均 IKI の横に括弧で表示する（例「168.8 ms 平均 IKI（72 WPM）」）。ランキングには表示しない。
- ミスなく打てば `WPM ≒ 12000 / 平均 IKI` になる。

- 1語 = 5文字として数える（スペースや記号も1文字）。
- 間違えたまま残っている文字は数えない。直せば数える。
- 打っている途中は画面上部の平均 IKI の横に括弧で表示する。打ち始め直後は値が極端に跳ねるため、経過2秒未満の間は `-` と表示する。
- 結果画面では整数に丸める。

## 正確率

```
正確率(%) = (お題の文字数 - 未修正の間違い) / お題の文字数 × 100
```

- **最後に残った文字**がお題とどれだけ合っているかの割合。
- 間違えても Backspace で直して打ち直せば、正確率には含めない（そのミスにかかった時間は平均 IKI に含まれる）。直さずに残した間違いだけが正確率を下げる。
- 打っている途中は「今の入力のうちお題と合っている文字 ÷ 今の入力の文字数」。まだ1文字も打っていないときは 100%。
- 間違えた打鍵の回数は「ミス」として別に数えて表示する（正確率とは別）。
- 計測中の表示は小数点以下切り捨て、結果画面では小数第1位まで表示する。

## ミス

- 入力した瞬間にお題と違っていた文字を1回とカウントする。
- 同じ位置で2回間違えれば2回と数える。
- 画面上では、間違っている文字を赤で表示する。直すと消える。

## キーごとの間隔

結果画面の「キーごとの間隔」タブに、お題の文字ごとの打鍵間隔を棒グラフで表示する。実装は `js/rhythm.js`。

- **間隔**：その文字を入力した時刻と、直前の打鍵（Backspace を含む）の時刻の差(ms)。
- **1文字目**：計測開始の打鍵なので間隔はない。棒も数値も出さない。
- **打ち直した位置**：最後に打ったときの間隔で上書きする。つまり直前の Backspace からの時間になる。
- **ミスあり**：その位置で一度でもミスしたら、文字を赤くして下線を付ける。直しても印は残る。
- **点線の平均**：間隔がある全文字の「最後の打鍵の間隔」の平均（ms、整数に丸める）。点線と凡例に表示し、棒と n-gram の色の基準にする。打ち間違いや Backspace の時間を含まないので、結果の平均 IKI（上記）より小さくなる。スペースやミスのあった位置も含む。
- **棒の色**：間隔が 0 に近いほど青、平均で緑、平均の2倍以上で赤。その間は色相がなめらかに変わる（色相は `style.css` の `--rh-hue-*`）。
- **棒の高さ**：間隔に比例する。平均の3倍を超える間隔は3倍で頭打ちにし、棒の上端に白い区切り線を付ける。数値は実際の値を表示する。
- **スペース**は `_` で表示する。単語の途中では折り返さない。

## 入力の制限

- ペースト、ドラッグ＆ドロップ、切り取りは無効。
- キャレットは常に入力の末尾。矢印キー、Home / End、PageUp / PageDown、Enter、Tab は無効。
- お題より長くは入力できない。

## やり直し

- Esc または「もう一度」：同じお題で最初から。
- 「次のお題」：別のお題に変えて最初から。
- どちらも打鍵数・ミス・時間をすべてリセットする。

## 日本語（ローマ字入力・かな配列）

上の決まりは英語のもの。日本語では次のように読み替える。判定は `js/typer.js`（ローマ字とかな配列で共通）、受け取りは `js/app.js` の `handleJaKey`。打ち方の一覧は、ローマ字（「配列」が QWERTY のとき）は `js/romaji.js`、かな配列（キー配列のページで登録した配列を選んだとき）はその割り当て表から `js/kana-layout.js` で作る。ローマ字の決まり（「ん」「っ」など）を除き、かな配列でも同じ。

- **お題と文字数**：打つのは読み（ひらがな）。文字数は読みのかなの数。
- **入力の受け取り**：IME は使わない。keydown の `e.code`（押したキーの物理的な位置）から US キーボードの文字を求めて判定する（OS の入力設定によらない）。IME がオンのまま打たれたら（`e.key` が `"Process"`）受け付けず、オフにするよう表示する。
- **判定**：お題のかなを読める打ち方の一覧（例「し」= shi・si・ci、「しゃ」= sha・sya、または「し」＋「ゃ」）のどれかの続きなら正解。
  - 「ん」は `nn`・`xn`。次のかなが母音・ナ行・ヤ行で始まらないときは `n` 1つでもよい（次のキーで確定する）。お題の最後の「ん」は `nn`。
  - 「っ」は `xtu`・`ltu` などのほか、次のかなの最初の子音を重ねてもよい（`kka` など。母音と n は重ねられない）。
- **間違い**：どの打ち方の続きにもならないキーを押したら、今のかな1文字を間違いとして確定し（赤）、次のかなに進む。英語と同じく、直さずに先へ進める。
- **Backspace**：打ちかけのキーがあれば1つ消す。なければ最後に確定したかなを消す（「しゃ」のように2文字まとめて打ったものは2文字とも消える）。
- **計測**：最初のキーを押した瞬間に開始し、最後のかなが確定した瞬間に終了する。
- **平均 IKI（キーあたり）** ＝ 経過時間 ÷（最後に残った正しいかなを打ったキーの数 − 1）。ミスや Backspace の時間も含む。打っている途中は、ここまでの正しいキーの数で割る。
- **かな/分**（英語の WPM の代わりに括弧で表示）＝ 正しいかなの数 ÷ 経過分数。
- **正確率**：英語と同じく（かなの数 − 未修正の間違い）÷ かなの数。
- **ミス**：間違えたキーの数（間違いとして確定したかなの数と同じ）。
- **キーごとの間隔**（結果画面のグラフ）：最後に残ったかなを打ったキーごとに、棒を1本出す。間隔は、そのキーを押した時刻と直前のキー（Backspace を含む）の時刻の差。最初のキーは間隔なし。キーの文字（QWERTY）を棒の下に、そのかなをさらに下の段に書く。ミスのあったかなは、キーとかなを赤くする。どのかなの後でも折り返し（「、」「。」「ー」と小さいかなは前のかなと離さない）、「。」の後で改行する。点線は表示したキーの間隔の平均で、修正の時間を含まないので結果の平均 IKI より小さくなる。生データの `intervals` は、かなごとの間隔（そのかなの最初のキーの直前のキーから、最後のキーまで。2文字まとめて打ったときの2文字目は 0）を保存する。
- **手引き**：ローマ字入力のときは、お題の上に次に打つローマ字を表示する。打ちかけ（灰色）・今のかなの残り（青）・その先（薄い灰色）。打ち方を変えると手引きも合わせて変わる（`si` と打てば `si`）。かな配列のときは出さない（IME がオンのときの注意だけ出す）。

### かな配列

- **配列の選択**：タイピング画面の「配列」に、キー配列のページ（`docs/layouts.md`）で保存したかな配列を、配列名のまま出す。日本語のときだけ選べる。かな配列を選んだまま英語に切り替えたら、QWERTY に戻す。
- **判定**：割り当て表を逆に引き、お題のかなを打てるキーの並びの一覧を作る（例「ぴゃ」は `j'e`、または「ぴ」の `j'` ＋「ゃ」の並び）。お題を手がかりにするので、後置シフトのように次のキーを見ないと決まらない並びも迷わない（お題が「っ」なら `j` ですぐ確定、「ぴ」なら `j` は打ちかけで `'` で確定）。
- **配列にないかな**：割り当て表にないかな（「ー」「、」など）は、そこまで進んだときに間違いとして確定して飛ばす（赤）。ミスに数えるのはその位置で1回だけ（打ち直して何度通っても増やさない）。直せないので未修正の間違いとして残り、正確率が下がる。飛ばしたかなの後ろで Backspace を押すと、飛ばしたかなと、その前に打ったかなを一緒に消す（`"-"` の行は1行にまとめる）。結果のグラフでは、飛ばしたかなに空の列を1つ置く。
- **記録**：`keyLayout` に配列名を入れる。ランキングと推移は配列ごとに分かれる。
