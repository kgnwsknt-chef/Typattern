# IKI 測定

実際の語では出てこない、または回数が少ない bigram（続けて押す2つのキーの組）の IKI を測るための練習モード。設定の文字から意味のない短い語を作って打つ。実装は `js/iki-measurement.js`（語の作り方・1回目を数えない位置・結果の表）と `js/app.js`。練習モードに共通の決まりは `docs/practice.md`。

将来、trigram を測ることも考えて、名前は「bigram」を付けずに「IKI 測定」とする。

## モード

- タイピング画面の「モード」で「IKI 測定（練習モード）」を選ぶ。`mode` は `iki-measurement`、`textId` も `iki-measurement`。
- 練習モードとして記録する（`practice: true`）。レベルの達成度・ランキング・記録のページの推移には入れず、IKI・ミスタイプのページには入れる。絞り込みの「練習モード以外」で除け（IKI・ミスタイプのページでは「IKI 測定以外」でこのモードだけを除ける）、「モード」でこのモードだけを選ぶこともできる（`docs/records.md`）。
- 苦手な単語・他では速い bigram の候補は、練習モードの回を使わないので、このモードの回は入らない（`docs/weak-words.md`）。

## 打ち方と記録

- **言語は英語、配列は QWERTY**：このモードを選ぶと、タイピング画面の「言語」を英語、「配列」を QWERTY にし、このモードの間はどちらも選べなくする。ブラウザが覚えている言語・配列は変えず、ほかのモードに切り替えたら、覚えている言語・配列に戻す。
  - 言語の値を別に作らず英語にするのは、モード（`iki-measurement`）で絞り込めば分けられ、IKI のページの英語・QWERTY の表に、ふだんの打鍵と並べて見られるため。
- **押すキーの位置で打つ**：お題の文字は QWERTY の文字で、押したキーの位置（e.code から求めた QWERTY の文字）で判定する（OS の入力設定によらない）。IME がオンのまま打たれたら受け付けず、オフにするよう表示する。
- **記録の言語・配列**：`lang` は `en`、`keyLayout` は `qwerty` で記録する。IKI のページでは、英語・QWERTY の bigram のデータとして入る。
- 計測（平均 IKI・WPM・正確率・ミス・キーごとの間隔）は英語の決まりと同じ（`docs/measurement.md`）。

## お題

- **1回のお題**：10語。1語を5回続けて打ち、語の間はスペース（例 `qazqzz qazqzz qazqzz qazqzz qazqzz zp//z/ …`）。同じ語は1回のお題に2回出さない（5回ずつのまとまりが分からなくなるため）。
- **語の決まり**：1語は3〜6文字。1語に使う文字は3種類まで（覚えて打ちやすくするため）。同じ文字を続けるのは3つまで（`zzz` はよく、`zzzz` は作らない。数えにくく打ちにくいため）。文字は設定の「測る文字」（`ikiMeasurementChars`。`docs/settings.md`）にあるものだけを使う。
- **語の作り方**：設定の「語の作り方」（`ikiMeasurementPick`）で選ぶ。お題を出すたびに作る（「もう一度」は同じお題）。
  - **少ない bigram**（初期値。`"least"`）：測る文字でできる bigram（同じ文字の組 `qq` も含む）を、記録の中の回数が少ない順に使う。
    - 回数は、全部の言語・配列・モードの記録をまとめて数える（IKI のページと同じ数え方。IKI 測定の回は各語の1回目を数えない）。モードを選んだときに数え、IKI 測定の回を打ち終えるたびに、その回の分を足す。
    - 1語ずつ、回数の一番少ない bigram（同じ回数ならランダム）から始め、最後の文字に続く bigram の回数が一番少ない文字を足していき、6文字にする。文字の種類が3つになったら、その3種類の中から選ぶ。
    - 作った語の bigram は、その分（1回出すと数える回数の4回）を回数に足してから比べる（同じ語の中でも、使うたびに足す）。同じ bigram ばかりにならず、回数の少ない bigram が順に出るようにするため。
  - **文字列から**（`"random"`）：測る文字からランダムに3種類（測る文字が2つなら2種類）を選び、3〜6文字（長さもランダム）の語にする。選んだ文字はどれも1回は使う。

## 1回目を数えない

- 各語の5回のうち1回目は、慣れる前で遅くなるので、IKI のページ（bigram・trigram・キーごとの IKI・2次元ヒストグラム。`docs/analysis_iki.md`）と、「少ない bigram」の回数に入れない。1回目の文字を打ったキーが絡む組を除く（`IkiMeasurement.firstRepPositions`。お題の並びから、同じ語が続くまとまりの最初の語の位置を求める。記録の形は変えない）。
- ミスタイプのページには、1回目も入れる（慣れる前のミスも、ミスのデータとして使う。`docs/analysis_mistype.md`）。
- 結果画面の「キーごとの間隔」と平均 IKI などの数値は、1回目も含む（ほかのモードと同じ）。

## 結果画面

- 練習モードの結果（順位・レベルは出さない。`docs/practice.md`）に加えて、「語ごとの IKI（1〜5回目）」の表を出す。
- 列は、語・1〜5回目・平均・ミス。
  - **1〜5回目**：その回に語の2文字目から打った、文字ごとの最後の打鍵の間隔の平均（ms/文字、整数）。1文字目は直前のスペースからの間隔なので入れない。間隔がなければ `-`。1回目の列は、IKI のページに入れないので灰色にする。
  - **平均**：2〜5回目の値の平均。
  - **ミス**：間違えたキーがあった回の数（例 `1 / 5`）。
- 2〜5回目と平均の色は、この回の全部の間隔の平均を基準にした速さの色（`Rhythm.color`）。5回でどう速くなったかを見るための表。
