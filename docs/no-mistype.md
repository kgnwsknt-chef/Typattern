# ノーミス連続タイプ

ミスをせずに、どこまで続けて打てるかに挑戦するモード（ゲーム性を持たせるため）。練習モード（`docs/practice.md`）とは別のモードで、`mode` は `no-mistype`。お題の単語の選び方と自己ベストは `js/no-mistype.js`、タイピング画面は `js/app.js`、記録のページは `js/stats.js`・`js/trend.js`。計測の決まりは `docs/measurement.md`、記録の形は `docs/storage.md`。

## お題

- 単語を、単語の間にスペースを入れて途切れなく出す（単語モードと同じく、日本語もスペースを打つ）。お題の終わりはなく、打っている位置からお題の終わりまでが 200 文字より短くなったら、4行ずつ後ろに足していく。
- 言語・配列は、画面上部で選んでいるもの（日本語のローマ字・英語の配列・かな配列も使える）。
- **単語の選び方**：何語目かで、選ぶ単語リストを広げる。その中からランダムに選び、同じ単語は 50 語のあいだ重ねない。
  - 日本語：
    | 何語目 | 単語リスト |
    | --- | --- |
    | 1〜100 | キー配列習得の単語リスト A |
    | 101〜300 | 単語リスト A・B |
    | 301〜500 | 単語モードの単語リスト（`wordlists/ja/`。今は basic1000）・単語リスト A・B |
    | 501〜 | 単語モードの単語リスト・単語リスト A〜D |
  - 単語リスト A〜D は `wordlists/layout-learning/`（`docs/layout-learning.md`）。
  - 英語：最初から最後まで、単語モードの単語リスト（`wordlists/en/`。今は basic1000）。
  - かな配列では、割り当て表にないかなを含む語は使わない（配列にないかなはミスになり、その場で終わってしまうため。`docs/measurement.md` の「配列にないかな」）。その段の単語リストに使える語がなければ、使える単語リストを全部使う。
- **行**：単語を、英語は 48 文字ほど、日本語は読みで 40 文字ほどで行に分ける（単語の途中では分けない）。日本語の1行は、表示する文の行と読みの行の組。
- **見せ方**：お題は4つの段で見せ、行を1段目・2段目・3段目・4段目・1段目 …と順に入れる。
  - はじめは1〜4行目を出す。
  - 打ち終えた行は隠し、その段は空ける。
  - 打っている行と、その2行先までを出す（3行目まで進むと、5行目を1段目に出す。2段目は空のまま）。
  - 4段目の行を打ち終えたら、1段目の行に移る。
- 「もう一度（Esc）」も「次のお題（Shift+Enter）」も、新しい単語の並びで最初から。

## ルール

- お題と違うキーを1回でも押したら、その場で終わる（日本語は、どの打ち方の続きにもならないキー。`docs/measurement.md` の「日本語」）。
- Backspace は効かない（押しても何もしない）。
- 速さの下限はない。インジケーター（`docs/levels.md`）は出さない。
- 入力がないときの停止は、ほかのモードと同じ（止まったら記録しない。`docs/measurement.md` の「計測」）。
- 1文字目でミスしたときは記録しない。

## 数えるもの

- **文字数**：ミスの前までに正しく打った文字の数（日本語はかなの数。単語の間のスペースも数える）。これを競う。
- **打鍵数**：ミスの前までに正しく打った文字（日本語はかな）を打ったキーの数（Shift は数えない）。日本語で、ミスしたかなの打ちかけのキーは数えない。
- **時間**：最初のキーから、ミスの前に最後に正しく打った文字（かな）のキーまで。
- **速さ**：平均 IKI（時間 ÷（打鍵数 − 1））と、WPM（日本語はかな/分）。求め方は `docs/measurement.md` と同じ。
- **自己ベスト**：言語ごとに、文字数の一番多い回（同じなら時間の短い回）。配列では分けない。

## 結果画面

- 結果の一番上に「ミスなしで N 文字」と、打鍵数・時間・平均 IKI・速さを出す。
- 自己ベストを超えたら「自己ベスト更新！」（これまでの自己ベストも）と赤字で出す。超えなければ自己ベストの文字数と日付を出す。
- その下の数字は、ほかのモードと同じ並び（平均 IKI・正確率 100%・時間・ミス 1）。順位とレベルは出さず、「ランキング」のタブも出さない。
- 「キーごとの間隔」のグラフは、ミスの前までの分。

## 記録

- 概要（`sessions`）と生データ（`raws`）を保存する。`practice` は付けない。形は `docs/storage.md`。
  - お題（`textLength`・生データの `text`）は、ミスの前までに切り詰める。`textId` は `"no-mistype"`。
  - 正確率は 100、未修正の間違いは 0、ミスは 1。打鍵数（`keystrokes`）は、ミスのキーと打ちかけのキーも含めて押したキーの数。日本語の `correctKeys` は上の打鍵数。
  - 生データの `events` には、ミスのキーまで残す。
- **入れないところ**：レベルの達成度のレベル・ランキング（結果画面と記録のページ）・IKI のページ・ミスタイプのページ・苦手な単語のページ（言語・配列で差のある bigram の比べも含む）。
- **記録のページ**（`docs/records.md`）：
  - レベルの達成度の表の右に「ノーミス連続タイプ」の列を足し、言語ごとに自己ベストの文字数・打鍵数・時間・平均 IKI・速さ・日付・配列を出す（絞り込みは効かない）。
  - 絞り込みのモードで「ノーミス連続タイプ」を選んだときだけ、推移のグラフにノーミス連続タイプの回を描く（「すべて」には入れない）。上段は文字数（1回ごとは自己ベストの線、日ごと・月ごとはその日（月）の平均と最高 ◇）、下段は平均 IKI。ランキングは出さない。
