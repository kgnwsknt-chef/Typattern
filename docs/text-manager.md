# お題の追加・閲覧・編集

お題のページ（`text-manager.html`）の決まり。自分の文章や単語リストをファイルから読み込んで、お題に足す。追加したお題の閲覧・編集・削除もここでする。実装は `js/text-manager.js`（ページ）と `js/custom-texts.js`（読み取りと確かめ。タイピング画面と共通）。保存形式は `docs/storage.md` の「追加したお題」。

- **開き方**：設定のページの「登録」の「お題」から開く。このページを開いている間は、一番上のリンクの「設定」を強調し、ページの上に「設定 › お題」の戻り道を出す。
- 最初から入っているお題（`texts/`・`wordlists/` のファイル）はそのまま使い、追加したお題はそれと一緒に出てくる。
- 確認のダイアログ（`confirm`）は使わない（出さないブラウザでは操作できなくなるため）。上書きは「閲覧・編集」から、削除はボタンの2回押しで確かめる。

## 追加のしかた

1. 言語（英語・日本語）と種類（文章・単語リスト）を選び、名前を入れる。
2. ファイルを選ぶか、枠に貼り付ける（ファイルを選ぶと枠に読み込み、名前が空ならファイル名（拡張子を除く）を入れる）。
3. 「読み込んで確かめる」：問題があれば行番号と理由を一覧で出す。問題がなければ、長さと使うモード（例「291文字（文章モードで使います）」）・置き換えた文字・お題の初めを出し、「保存する」が押せるようになる。
4. 「保存する」：保存して、フォームを空に戻す。同じ言語に同じ名前のお題がすでにあれば保存させず、別の名前にするか、一覧の「閲覧・編集」から直すよう知らせる。

- 言語・種類・名前・中身を変えたら、もう一度確かめるまで保存できない。

## 追加したお題の一覧

名前・言語・種類・長さ（文字・かな・語）・モード・保存した日を出し、1件ごとに「閲覧・編集」「削除」のボタンを付ける。フォームに出しているお題の行には色を付ける。

- **閲覧・編集**：そのお題を上のフォームに出し（中身は読み込んだときの書き方のまま）、見出しを「お題の編集」にして、「「名前」（言語）を表示しています」と「編集をやめる」を出す。保存のボタンは「上書き保存する」になる。直して確かめてから押すと上書きする。
  - 名前を変えて保存すると、新しい名前で保存し、前の名前のお題は消す（名前の付け替え。前の名前で打った記録は残る）。新しい名前がほかのお題と同じなら保存させない。
  - ファイルを選び直して中身を入れ替えることもできる。
  - 保存するか「編集をやめる」を押すと、新しく追加する状態に戻る（フォームは空になる）。
- **削除**：1回押すと「本当に削除」（赤）に変わり、4秒以内にもう一度押すと消す（4秒たつと元に戻る）。そのお題で打った記録は残る（記録の `raws.text` にお題の文がそのまま残っているので、記録のページのグラフも出せる）。フォームに出しているお題を消したら、新しく追加する状態に戻る。

## 最初から入っているお題の一覧

「追加したお題」の下に、アプリに最初から入っているお題（`texts/index.json` の題材の `.txt`（文章）と `_short.txt`（短い文章）、`wordlists/index.json` の単語リスト）を、名前・言語・種類・長さ・モードの一覧で出す。

- **閲覧だけ**できる：「閲覧」で上のフォームに、ファイルの中身をそのまま出す。見出しを「お題の閲覧」にして、「最初から入っているお題です。閲覧だけで、編集・保存はできません」と「閲覧をやめる」を出す。入力欄・名前・言語・種類は読み取りだけにして同じ色（`--head-bg`）にそろえ、ファイルの選択もできなくして、「読み込んで確かめる」「保存する」は隠す。長さとモードはメッセージ欄に出す。編集・削除のボタンはない。
- 「閲覧をやめる」か、ほかのお題の「閲覧」「閲覧・編集」を押すと、閲覧をやめる。閲覧していた中身はフォームに残さない（追加の下書きに混ざらないように）。
- モードはファイルで決まる（`.txt` は文章、`_short.txt` は短い文章、単語リストは単語）。追加したお題のように長さで振り分けはしない。
- 中身の読み取り（長さ）は、追加したお題と同じ `CustomTexts.parse` を使う。ファイルの読み込みには、ページの `?v=` の番号を付ける。

## 書き方

`#` で始まる行と空の行は読み飛ばす。

| 言語・種類 | 書き方 |
| --- | --- |
| 英語・文章 | 文をそのまま書く。改行や連続した空白は、スペース1つにまとめる（最初から入っているお題と同じ） |
| 日本語・文章 | 「表示する文」と「読み（ひらがな）」を1行ずつ交互に書く（`texts/ja/` と同じ）。読みはスペースなしでつなげる |
| 英語・単語リスト | 1行に1語 |
| 日本語・単語リスト | 1行に1語。「表示する語」と「読み」を**タブかスペース**（半角・全角。いくつ続いてもよい）で区切る。かなだけの語は1列でもよい（最初から入っている単語リストはタブ区切りだけ） |

## 確かめること

- **名前**：空でないこと。`/` と `\` は使えない。同じ言語の、最初から入っているお題・単語リストの名前（`texts/index.json`・`wordlists/index.json`）と同じ名前は使えない。
- **英語**：US キーボードで打てる文字（スペースと ASCII の英数字・記号）だけ。よくある文字は打てる形に直す（“ ” → `"`、‘ ’ → `'`、– — → `-`、… → `...`、全角スペースなど → 半角スペース）。英語の単語リストは、1行にスペースを含まない1語。
- **日本語の読み**：ひらがなと「、」「。」「ー」だけで、ローマ字で打てること（`js/romaji.js` の打ち方の一覧にあること）。カタカナはひらがなに直し、読みの中のスペースは除く。最初から入っているお題と同じく、Shift を使う文字は入れない。日本語の文章は、表示する文と読みの行の数がそろっていること。
  - **読みにアルファベットは入れられない**：アルファベットそのものを打つことには対応しない。表示する文にはアルファベットを入れてもよい（画面に出すだけ）が、読みはその読み方をひらがなで書く（例：表示「QWERTY 配列」、読み「くわーてぃはいれつ」）。読みにアルファベットがあると、「読みにローマ字で打てない文字があります」として読み込めない。
- **長さ**：文章は 30 文字（日本語は読みの 30 かな）以上。数文字では1回のつまずきで平均 IKI が大きく変わり、測る意味が薄いため。短い1文なら入る長さにしている。これより短い文章は「お題が短すぎます」として読み込めない（この決まりより前に保存したお題は、短くてもそのまま使える。編集して保存し直すときは確かめる）。単語リストは、全部の語（日本語は読み）をスペースでつないで300文字（かな）以上になること（単語モードのお題は約300文字なので、それより短いリストでは短いお題になってしまうため）。

## どのモードで使うか

保存したときの長さで決める（文章・短い文章に当たる文章は「その他」を選ぶこともできる。下記）（英語は文字数、日本語は読みのかなの数。スペースを含む）。最初から入っているお題（約300文字・約90文字）に、およそ2割の幅を持たせた範囲。

| 種類・長さ | モード |
| --- | --- |
| 文章 240〜360文字 | 文章（`normal`） |
| 文章 70〜110文字 | 短い文章（`short`） |
| 文章 それ以外 | その他（`other`） |
| 単語リスト | 単語（`words`） |

- **その他を選べる**：長さから文章・短い文章に当たる文章は、「読み込んで確かめる」の後に「使うモード」の選択を出し、長さから決まったモード（例「文章（長さから自動）」）か「その他」かを選んで保存できる（初めは長さから決まったモード）。メッセージ欄の「〜モードで使います」も選んだモードに合わせ、長さからのモードと違えば「（長さからは文章）」のように添える。選んだものは確かめ直しても変わらない（フォームを空にすると、長さからのモードに戻る）。編集するときは、保存したモードが選ばれた状態で出す。長さが文章・短い文章に当たらない文章はいつも「その他」、単語リストはいつも「単語」で、選ぶものはない。
- **その他になる理由を出す**：長さが当たらずに「その他」になる文章は、確かめたときと保存したときのメッセージに理由を添える（例「短い文章（70〜110文字）まで 20文字足りないため」「短い文章（70〜110文字）より 40文字多く、文章（240〜360文字）まで 90文字足りないため」「文章（240〜360文字）より 40文字多いため」。日本語は「かな」）。種類で「文章」を選んだのに長さで「その他」になるので、このメッセージは赤の太字で強調する。「使うモード」でその他を選んで保存したときは、そう選んだためと添える。

- 文章・短い文章・単語に入ったお題は、最初から入っているお題と同じ候補になる（お題を選ぶときは、候補の中から同じ確からしさで1つ選ぶ。単語モードは単語リストを1つ選び、その中から約300文字のお題を作る）。レベル・ランキングもいつもどおり。
- **その他**（`other`）は、追加したお題のうち、文章・短い文章のどちらの長さにも入らないものだけのモード。タイピング画面の「モード」に「その他（追加したお題）」として出す。長さがまちまちなので、短い文章と同じく**レベルの達成には数えない**（`docs/levels.md`）。ランキング・推移は、ほかのモードと同じく言語・モード・配列ごとに分かれる。その言語の「その他」のお題がまだないときは、お題の代わりに追加のしかたを案内する。
- 記録の `textId` には、追加したお題の名前を入れる。

## 書き出し・読み込み

追加したお題は、設定のページの「記録を書き出す」のファイルに入る（`texts`）。読み込むときは、同じ言語・名前のお題がなければ足す。同じで中身（`source`）も同じなら飛ばし、中身が違えば今のものを残して知らせる（キー配列と同じ扱い）。
