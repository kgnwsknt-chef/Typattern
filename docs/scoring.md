# 採点ルール

WPM・正確率・ミスの判定方法。実装は `js/app.js`。ルールを変えるときは、このファイルとコードを一緒に直す。

## 用語

| 用語 | 意味 |
| --- | --- |
| お題 | 打つべき英文（`js/passages.js`） |
| 入力 | 今入力欄に入っている文字列（Backspace で消した分は含まない） |
| 打鍵数 | 文字を1文字入力するたびに +1。Backspace などの削除は数えない |
| ミス | 入力した瞬間に、お題の同じ位置の文字と違っていた打鍵の数 |
| 正しい文字数 | 現在の入力のうち、お題の同じ位置の文字と一致している文字の数 |

## 文字の正誤

- 入力の i 文字目と、お題の i 文字目を1文字ずつ比べる。
- 完全一致のみ正解。大文字と小文字、記号、スペースも区別する。
- 判定は `isCorrect(typed, expected)` にまとめてある。日本語対応では、ここを言語ごとに差し替える。

## 計測

- **開始**：最初の1文字を入力した瞬間。
- **終了**：入力の長さがお題と同じになった瞬間。間違いが残っていても、最後の位置まで打てば終了する。
- 制限時間はない。

## WPM

```
WPM = (正しい文字数 / 5) / (経過秒数 / 60)
```

- 1語 = 5文字として数える（スペースや記号も1文字）。
- 間違えたまま残っている文字は数えない。直せば数える。
- 打ち始め直後は値が極端に跳ねるため、経過2秒未満の間は画面に `-` と表示する。
- 結果画面では整数に丸める。

## 正確率

```
正確率(%) = (打鍵数 - ミス) / 打鍵数 × 100
```

- 一度間違えた打鍵は、あとで Backspace で直してもミスのまま残る。
- Backspace で消して打ち直した文字は、打鍵数にもう一度数える。
- まだ1文字も打っていないときは 100%。
- 計測中の表示は小数点以下切り捨て、結果画面では小数第1位まで表示する。

## ミス

- 入力した瞬間にお題と違っていた文字を1回とカウントする。
- 同じ位置で2回間違えれば2回と数える。
- 画面上では、間違っている文字を赤で表示する。直すと消える。

## 入力の制限

- ペースト、ドラッグ＆ドロップ、切り取りは無効。
- キャレットは常に入力の末尾。矢印キー、Home / End、PageUp / PageDown、Enter、Tab は無効。
- お題より長くは入力できない。

## やり直し

- Esc または「もう一度」：同じお題で最初から。
- 「次のお題」：別のお題に変えて最初から。
- どちらも打鍵数・ミス・時間をすべてリセットする。
