# 採点ルール

WPM・正確率・ミスの判定方法。実装は `js/app.js`。ルールを変えるときは、このファイルとコードを一緒に直す。

## 用語

| 用語 | 意味 |
| --- | --- |
| お題 | 打つべき英文（`texts/` の `.txt`。改行や連続した空白は1つのスペースにそろえる） |
| 入力 | 今入力欄に入っている文字列（Backspace で消した分は含まない） |
| 打鍵数 | 文字を1文字入力するたびに +1。Backspace などの削除は数えない |
| ミス | 入力した瞬間に、お題の同じ位置の文字と違っていた打鍵の数 |
| 正しい文字数 | 現在の入力のうち、お題の同じ位置の文字と一致している文字の数 |

## 文字の正誤

- 入力の i 文字目と、お題の i 文字目を1文字ずつ比べる。
- 完全一致のみ正解。大文字と小文字、記号、スペースも区別する。
- 判定は `isCorrect(typed, expected)` にまとめてある。日本語対応では、ここを言語ごとに差し替える。

## 計測

- **開始**：最初の1文字を入力した瞬間。
- **終了**：入力の長さがお題と同じになった瞬間。間違いが残っていても、最後の位置まで打てば終了する。
- 制限時間はない。

## 平均 IKI（結果の主な指標）

```
平均 IKI(ms) = 経過時間(ms) / (お題の文字数 - 1)
```

- お題1文字あたりにかかった時間。結果画面で一番大きく表示し、ランキングの基準にする。
- 打ち間違えた文字や Backspace にかかった時間も含む（ミスをするとその分遅くなる）。ミスなく打てば、打鍵の間隔の平均と同じ値になる。
- 1文字目は計測開始の打鍵なので、間隔の数は「文字数 - 1」。
- 結果画面では小数第1位まで表示・保存する。
- 打っている途中も画面上部に表示する（括弧で WPM）。途中の値は「経過時間 ÷（ここまでに進んだ文字数 − 1）」で、整数に丸める。最後まで打つと結果の値と同じになる。経過2秒未満の間は `-`。
- 「キーごとの間隔」のグラフや n-gram で使う間隔（各文字の最後の打鍵の間隔）とは別のもの（下記）。

## 未修正の間違い

- 終了した時点で、お題と違ったまま残っている文字の数。
- 間違えた打鍵はその時点でミスとして数えているので、正確率にはすでに反映されている。結果画面では「ミス（未修正 N）」と表示する。

## WPM（括弧で表示）

```
WPM = (正しい文字数 / 5) / (経過秒数 / 60)
```

- 結果画面では平均 IKI の横に括弧で表示する（例「168.8 ms 平均 IKI（72 WPM）」）。ランキングには表示しない。
- ミスなく打てば `WPM ≒ 12000 / 平均 IKI` になる。

- 1語 = 5文字として数える（スペースや記号も1文字）。
- 間違えたまま残っている文字は数えない。直せば数える。
- 打っている途中は画面上部の平均 IKI の横に括弧で表示する。打ち始め直後は値が極端に跳ねるため、経過2秒未満の間は `-` と表示する。
- 結果画面では整数に丸める。

## 正確率

```
正確率(%) = (打鍵数 - ミス) / 打鍵数 × 100
```

- 一度間違えた打鍵は、あとで Backspace で直してもミスのまま残る。
- Backspace で消して打ち直した文字は、打鍵数にもう一度数える。
- まだ1文字も打っていないときは 100%。
- 計測中の表示は小数点以下切り捨て、結果画面では小数第1位まで表示する。

## ミス

- 入力した瞬間にお題と違っていた文字を1回とカウントする。
- 同じ位置で2回間違えれば2回と数える。
- 画面上では、間違っている文字を赤で表示する。直すと消える。

## キーごとの間隔

結果画面の「キーごとの間隔」タブに、お題の文字ごとの打鍵間隔を棒グラフで表示する。実装は `js/rhythm.js`。

- **間隔**：その文字を入力した時刻と、直前の打鍵（Backspace を含む）の時刻の差(ms)。
- **1文字目**：計測開始の打鍵なので間隔はない。棒も数値も出さない。
- **打ち直した位置**：最後に打ったときの間隔で上書きする。つまり直前の Backspace からの時間になる。
- **ミスあり**：その位置で一度でもミスしたら、文字を赤くして下線を付ける。直しても印は残る。
- **点線の平均**：間隔がある全文字の「最後の打鍵の間隔」の平均（ms、整数に丸める）。点線と凡例に表示し、棒と n-gram の色の基準にする。打ち間違いや Backspace の時間を含まないので、結果の平均 IKI（上記）より小さくなる。スペースやミスのあった位置も含む。
- **棒の色**：間隔が 0 に近いほど青、平均で緑、平均の2倍以上で赤。その間は色相がなめらかに変わる（色相は `style.css` の `--rh-hue-*`）。
- **棒の高さ**：間隔に比例する。平均の3倍を超える間隔は3倍で頭打ちにし、棒の上端に白い区切り線を付ける。数値は実際の値を表示する。
- **スペース**は `_` で表示する。単語の途中では折り返さない。

## bigram・trigram

結果画面の「n-gram」タブに、連続する2文字（bigram）・3文字（trigram）ごとの平均 IKI（打鍵間隔）と出現回数を一覧で表示する。実装は `js/ngram.js`。

- **bigram の IKI**：「ab」の IKI は、a を打ってから b を打つまでの時間。「キーごとの間隔」で b の位置に記録した値と同じ。
- **trigram の IKI**：「abc」の IKI は、a→b と b→c の2つの間隔の平均（= a から c までの時間 ÷ 2）。1打あたりの値なので、bigramや「キーごとの間隔」と同じ尺度で比べられる。
- **例**：`point` → bigram `po` `oi` `in` `nt`、trigram `poi` `oin` `int`
- **ミスが絡んだものは除く**：含まれるどれかの文字の位置で一度でもミスしていたら数えない。打ち直した文字の間隔は「Backspace からの時間」で、文字から文字への動きではないため。
- **スペースを含むものは除く**：単語の中だけを数える。句読点（`s,` `e.` など）は数える。
- **大文字と小文字は区別する**：`Th` と `th` は別のもの。
- **平均 IKI**：同じ n-gram の IKI の平均（ms、整数に丸めて表示）。色は「キーごとの間隔」と同じ配色で、全体の平均間隔を基準にする。
- **並び順**：平均 IKI の昇順（速い順）が初期値。見出しをクリックすると昇順と降順が切り替わる。同じ平均なら回数の多い順。並び順は表ごとに持ち、やり直しても維持する。
- 1回しか出ないものも表示する。

## ランキング

結果画面の上部に今回の順位を、「ランキング」タブに Top 30 を表示する。実装は `js/store.js`（取り出し）と `js/ranking.js`（表）。

- **区分**：言語（`lang`）・モード（通常／`?short`）・キー配列（`keyLayout`）の組ごとに別のランキングにする。
- **並び順**：平均 IKI の小さい順。同じなら正確率の高い順。比べるのは保存した値（小数第1位に丸めた値）。
- **対象外**：正確率が 95% 未満の記録はランキングに載せない（記録は保存する。基準は `js/store.js` の `RANK_MIN_ACCURACY`。表示のたびに絞り込むので、基準を変えても記録を直す必要はない）。
- **同順位**：平均 IKI と正確率がどちらも同じなら同じ順位（1, 2, 2, 4 …）。
- **今回の順位**：「◯位 / その区分でランキングに載る記録数 回」と表示する。Top 30 に入らなくても順位は出す。対象外なら「ランキング対象外」と表示する。
- **表の列**：順位・平均 IKI・正確率・ミス・未修正・お題・日時（WPM は出さない）。
- 記録は自分のブラウザの中だけ（`docs/storage.md`）。

## 入力の制限

- ペースト、ドラッグ＆ドロップ、切り取りは無効。
- キャレットは常に入力の末尾。矢印キー、Home / End、PageUp / PageDown、Enter、Tab は無効。
- お題より長くは入力できない。

## やり直し

- Esc または「もう一度」：同じお題で最初から。
- 「次のお題」：別のお題に変えて最初から。
- どちらも打鍵数・ミス・時間をすべてリセットする。
