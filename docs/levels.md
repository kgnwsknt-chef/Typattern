# レベル

タイピングの習熟度をレベルで表し、次のレベルを目標にして練習できるようにする決まり。実装は `js/levels.js`（表と計算）と `js/app.js`（結果画面）。計測の決まり（平均 IKI・正確率）は `docs/measurement.md`。ルールを変えるときは、このファイルとコードを一緒に直す。

## レベルの決め方と達成レベル

### 1回ごとのレベル

- その回の文字/秒が、下のレベル表のどの値より速いかで決める（表の「文字/秒」より速ければそのレベル）。英語と日本語で表の値が違う。
- 文字数には、単語の間のスペースも1文字として数える（英語も、日本語の単語モードも同じ）。
- **ミスの扱い**
  - 経過時間にはミスや Backspace の時間も含むので、ミスはそのまま遅さとして効く。
  - **正確率がランキングの基準（95%）未満の回は「レベルなし」**。Typattern では間違いを直さずに先へ進めるので、直さずに打てば速く見えてしまうため。ミスの多さは「ミスも数えた正確率」として横に出す。

### 達成レベル

- その言語・モードの記録のうち、正確率95%以上の回の一番よいレベル。
- **言語ごとに分ける**：英語でAを達成していても、日本語では C まで、ということがある。
- **モードごとに分ける**：文章と単語は、それぞれ別の達成レベルを持つ。お題（題材）ごとには分けない。
- **短い文章（約90文字）は数えない**：短くて速く出やすいため。結果画面ではその回のレベルを出すが、達成には数えず、ランキングの表にもレベルを出さない。
- 配列（ローマ字・かな配列）では分けない。

### 目標

- 達成レベルの次のレベルを、自動で目標にする（利用者は選ばない）。まだ達成がなければ J。一番上の ZA を達成したら目標はない。
- 短い文章で打っているときは、文章の目標を使う。

## 表示

### 結果画面（実装済み）

- 順位の横に、今回のレベルと文字/秒（例「SB レベル（6.78 文字/秒）」）。正確率95%未満なら「-」で「正確率 95% 未満」と書く。
- その下に、達成レベルと次の目標までの差。例：「英語・文章の達成レベル：SB（今回 SB に上がりました！） ／ 次の目標 SA（6.90 文字/秒より速く）まで あと 0.12 文字/秒」
  - 今回で達成レベルが上がったら、強調して書く。
  - 短い文章のときは「短い文章は達成に数えません」と書き添える。今回の速さが目標に届いていても達成にならないときは、理由（文章で打つ／正確率95%以上）を書く。

### 打っている間のインジケーター（これから作る）

- 画面上部に、目標のペースとの差を色で出す。青は目標より速いとき、黄は目標の1つ下のレベルの範囲、赤はそれより遅いとき。

### 記録のページ（実装済み。決まりは `docs/records.md`）

- 一番上に「レベルの達成度」の表（言語 × モード）。達成レベルと達成した日、一番速い文字/秒、次の目標とあと何文字/秒か。全部の記録から出し、絞り込みは効かない。
- ランキングの表に「レベル（文字/秒）」の列（結果画面のランキングにも出る）。短い文章の回は空欄。
- 推移のグラフでは、達成レベルが上がった点を輪で囲み「SB達成」のように書く。点にマウスを乗せるとその回のレベルも出す。目標の線は引かない（推移の縦軸は平均 IKI で、日本語はキーあたりのため、文字/秒の目標と同じ軸に置けない）。
