# レベル

タイピングの習熟度をレベルで表し、次のレベルを目標にして練習できるようにする決まり。実装は `js/levels.js`（表と計算）と `js/app.js`（結果画面）。計測の決まり（平均 IKI・正確率）は `docs/measurement.md`。ルールを変えるときは、このファイルとコードを一緒に直す。

## レベルの決め方と達成レベル

### 1回ごとのレベル

- その回の文字/秒が、下のレベル表のどの値より速いかで決める（表の「文字/秒」より速ければそのレベル）。英語と日本語で表の値が違う。
- 文字数には、単語の間のスペースも1文字として数える（英語も、日本語の単語モードも同じ）。
- **ミスの扱い**
  - 経過時間にはミスや Backspace の時間も含むので、ミスはそのまま遅さとして効く。
  - **正確率 95% 未満の回は「レベルなし」**。Typattern では間違いを直さずに先へ進めるので、直さずに打てば速く見えてしまうため。ミスの多さは「ミスも数えた正確率」として横に出す。この 95% は固定で、設定のページで変えられるランキングの基準とは別（`js/levels.js` の `MIN_ACCURACY`）。

### 達成レベル

- その言語・モードの記録のうち、正確率95%以上の回の一番よいレベル。
- **言語ごとに分ける**：英語でAを達成していても、日本語では C まで、ということがある。
- **モードごとに分ける**：文章と単語は、それぞれ別の達成レベルを持つ。お題（題材）ごとには分けない。
- **短い文章（約90文字）は数えない**：短くて速く出やすいため。結果画面ではその回のレベルを出すが、達成には数えず、ランキングの表にもレベルを出さない。
- **その他（お題のページで追加した、長さが文章・短い文章に入らないお題。`docs/text-manager.md`）も数えない**：長さがまちまちで、比べられないため。扱いは短い文章と同じ。
- お題のページで追加したお題でも、文章・単語のモードに入ったもの（文章は 240〜360文字）は、ふつうに数える。
- 配列（ローマ字・かな配列）では分けない。

### 目標

- 達成レベルの次のレベルを、自動で目標にする（利用者は選ばない）。まだ達成がなければ J。一番上の ZA を達成したら目標はない。
- 短い文章で打っているときは、文章の目標を使う。

## 表示

### 結果画面（実装済み）

- 順位の横に、今回のレベルと文字/秒（例「SB レベル（6.78 文字/秒）」）。正確率95%未満なら「-」で「正確率 95% 未満」と書く。
- その下に、達成レベルと次の目標までの差。例：「英語・文章の達成レベル：SB ／ 次の目標 SA（6.90 文字/秒より速く）まで あと 0.12 文字/秒」
  - 今回で達成レベルが上がったら、「達成レベル：…」の代わりに「英語・文章レベル SB を達成！」と書き、その文と結果のレベルの値を赤の太字にする（`style.css` の `--level-up`。推移のグラフのレベル達成と同じ色）。
  - 短い文章・その他のときは「短い文章は達成に数えません」「その他は達成に数えません」と書き添える。今回の速さが目標に届いていても達成にならないときは、理由（文章で打つ／正確率95%以上）を書く。

### 打っている間のインジケーター（実装済み）

打っている間、今のペースが目標のレベルにどれだけ近いかを、帯の長さと色で知らせる。実装は `js/app.js` の `updatePace` と `js/levels.js` の `paceSteps`・`paceState`。

- **場所**：タイピング画面の平均 IKI などの数字の行と、お題の間に、20 マスの帯を1本出す。帯の上に「目標 SA（6.90 文字/秒より速く）　今 6.71 文字/秒（あと 1.6 秒）」と小さく書く（「あと」は下の遅れ。届いていれば出さない）。お題の中には印を付けない（先読みの邪魔にならないように）。
- **目標**：上の「目標」と同じ（その言語・モードの達成レベルの次。短い文章・その他は文章の目標）。お題を出すたびに、それまでの記録から決める。打ち終えて達成レベルが上がったら、次のお題から新しい目標になる。一番上の ZA を達成していて目標がないときは、帯を出さない。
- **今のペース**：（ここまでに進んだ文字数 − 1）÷ 経過秒数（文字/秒）。進んだ文字数は、間違えたまま進んだ文字も含む（最後まで打ったときに、その回のレベルの文字/秒と同じになる）。日本語はかなの数。
  - 文字の「今 ○ 文字/秒」「あと ○ 秒」は、この値そのもの（0.1 秒ごとと、キーを押すたびに変わる）。
- **帯の長さ（20 段）**：今のペースで基準の量（英語 400文字・日本語 280文字。レベル表の「基準の秒数」と同じ）を打つと何秒かかるかを求め、目標のレベルの秒数と比べる。
  - 目標の秒数より短い（目標のペースに届いている）：20 段（満タン）。
  - 届いていない：遅れ（かかる秒数 − 目標の秒数）1秒ごとに1段短くする。遅れ 0〜1 秒未満で 19 段、1〜2 秒未満で 18 段 … 19 秒以上で 0 段。
  - **帯の動かし方**：上で求めた段数（今のペースの段数）をそのまま出すと、1打ごとの揺れで帯が頻繁に変わって気が散る。そこで、帯に出している段数を 1.5 秒ごとに今のペースの段数と比べ、今のペースの方が多ければ右に進め（長くし）、少なければ戻す（短くする）。同じなら動かさない。動かす段数は差の半分（端数は切り捨て。ただし差が 1 段なら 1 段）で、差が大きいほど大きく動く（差 1〜3 段で 1 段、4〜5 段で 2 段、6〜7 段で 3 段 …。`js/app.js` の `PACE_STEP_MS`・`PACE_STEP_RATIO`）。
  - 出し始め（5文字目）は今のペースの段数から始め、そこから 1.5 秒ごとに比べる。打ち終えたときは、今のペースの段数にそろえる（結果のレベルと同じ判定にするため）。
- **色**：
  - **青**：目標の文字/秒より速い（20 段）。
  - **黄**：届いていないが、帯が真ん中より長い（11〜19 段。遅れ 9 秒未満）。
  - **赤**：帯が真ん中まで、またはそれより短い（0〜10 段。遅れ 9 秒以上）。
  - 黄と赤の境は帯の真ん中にそろえ、レベルの幅（A まで 13 秒、SJ から 2 秒）にはよらない。
  - **灰色**（色の付いたマスがない）：打ち始める前と、5文字（日本語はかな。打ちかけのローマ字は数えない）進むまで（打ち始め直後は値が跳ねるため。秒数で待つと、2秒の時点ではまだ数文字しか進んでおらず、大きな遅れとして出てしまうので、文字数で待つ。`js/app.js` の `PACE_MIN_CHARS`）。入力がないまま停止したときと、もう一度・次のお題でも空に戻す。
- **正確率**：打っている途中の正確率（`docs/measurement.md`）が、レベルの基準（95%。上の「ミスの扱い」と同じで固定。設定では変わらない）を下回ったら、帯の色を変え（青は黒、黄・赤はそれぞれ暗い黄・暗い赤。ペースのようにはならさず、下回ったその打鍵ですぐ変える）、文字に「正確率 95% 未満」と書き添える。このままではレベルが付かないことを知らせるため。
- **打ち終えたあと**：最後の色のまま残す。結果のレベルと同じ判定になる。
- 設定のページの「インジケーター」で消せる（初期値は ON。`docs/settings.md`）。色は `style.css` の `--pace-*`。

### 記録のページ（実装済み。決まりは `docs/records.md`）

- 一番上に「レベルの達成度」の表（言語 × モード）。達成レベルと達成した日、一番速い文字/秒、次の目標とあと何文字/秒か。全部の記録から出し、絞り込みは効かない。
- ランキングの表に「レベル（文字/秒）」の列（結果画面のランキングにも出る）。短い文章の回は空欄。
- 推移のグラフでは、達成レベルが上がった点を輪で囲み「英語・単語 SB達成」のように書く。点にマウスを乗せるとその回のレベルも出す。目標の線は引かない（推移の縦軸は平均 IKI で、日本語はキーあたりのため、文字/秒の目標と同じ軸に置けない）。
