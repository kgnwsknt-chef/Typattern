# キー配列習得の単語リスト C「割り当て文字を含む言葉（語彙少）」（docs/layout-learning.md）。単語モードには出さない（wordlists/index.json に入れない）。
# 1行に「表示する語<タブ>読み（ひらがな）」。かなだけの語は1列でもよい。# で始まる行は説明として読み飛ばす。
# 「頻出30字＋その割り当て文字」の言葉が少ない割り当て文字を含む言葉。ほかの字との組み合わせは問わない（読みは2〜5かな。5かなまでで20語に届かない割り当て文字だけ、8かなまでの言葉も入れた）。
# お題には、その割り当て文字と、それまでに覚えた字だけでできた言葉を選ぶ。単語リスト B にある、これらの割り当て文字を含む言葉もあわせて数える。
# どの割り当て文字の言葉かは、読みに使った字から決まる（並びと見出しは見やすさのため）。
