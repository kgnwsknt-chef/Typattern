# キー配列習得の単語リスト B「基本30字＋1の言葉」（docs/layout-learning.md）。単語モードには出さない（wordlists/index.json に入れない）。
# 1行に「表示する語<タブ>読み（ひらがな）」。かなだけの語は1列でもよい。# で始まる行は説明として読み飛ばす。
# どの言葉も、基本30字（い ん う の か た と し 、 く に て る は な こ が っ き 。 で す つ あ ら ま を さ り も）と、覚える単位1つだけでできている。
# 言葉が見つかりにくい単位（ぢ・づ・ぺ・小書き・ゔ・拗音や外来語の組の一部）だけは、基本30字以外の文字を2つまでにゆるめた（見出しに「ゆるめた」と書いた語）。
# どの単位の言葉かは、読みに使った字から決まる（並びと見出しは見やすさのため）。拗音・外来語の組を割り当て表に持たない配列では、
# 組の言葉は、小書き（ゃ・ゅ・ょ・ぃ・ぇ など）と、もう1つの字の言葉になる（例：「きゃく」は「ゃ」の言葉）。
