# キー配列習得の単語リスト B「基本30字＋1の言葉」（docs/layout-learning.md）。単語モードには出さない（wordlists/index.json に入れない）。
# 1行に「表示する語<タブ>読み（ひらがな）」。かなだけの語は1列でもよい。# で始まる行は説明として読み飛ばす。
# どの言葉も、基本30字（い ん う の か た と し 、 く に て る は な こ が っ き 。 で す つ あ ら ま を さ り も）と、覚える割り当て文字1つだけでできている。
# 言葉が見つかりにくい割り当て文字（づ・ぺ）だけは、基本30字以外の文字を2つまでにゆるめた（見出しに「ゆるめた」と書いた語）。
# B だけで20語ある1文字の割り当て文字を入れる（20語に満たない割り当て文字と、拗音・外来語の組は、単語リスト C・D）。どの割り当て文字の言葉かは、読みに使った字から決まる。
