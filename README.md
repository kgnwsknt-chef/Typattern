# Typattern

**打ち方のパターンを見るタイピング練習アプリ**

速さ（WPM）だけでなく、1文字ごとの打鍵の間隔（IKI: inter-key interval）や、bigram・trigram ごとの得意・不得意を記録して分析できます。ブラウザだけで動き、記録は自分のブラウザの中に保存されます。詳細は [docs/scoring.md](docs/scoring.md) を参照。

▶ **https://kgnwsknt-chef.github.io/Typattern/**
- 画面上部の「モード」で、文章（約300文字）・短い文章（約90文字）・単語（基本的な英単語1000語からランダムに約300文字）を選べる

## 記録の保存について

- 記録は**このブラウザの中だけ**（IndexedDB）に保存され、どこにも送信されません。
- ブラウザや端末が違うと、記録は別々になります。ローカル（`localhost`）と公開サイトの記録も別です。
- ブラウザの閲覧データを消すと記録も消えます。各ページ下部の「**記録を書き出す**」で JSON ファイルにバックアップし、「**記録を読み込む**」で戻せます。

保存形式は [docs/storage.md](docs/storage.md) を参照してください。

## お題を追加する

1. `texts/en/` に `題材名.txt`（約300文字）と `題材名_short.txt`（約90文字）を置く。1行70文字前後で改行してよい（読み込み時に1行にまとめられる）
2. `texts/index.json` の `"en"` に題材名を足す

## 単語リストを追加する

1. `wordlists/en/` に `リスト名.txt` を置く（1行1語。`#` で始まる行は説明として読み飛ばされる）
2. `wordlists/index.json` の `"en"` にリスト名を足す
