# Typattern

**打ち方のパターンを見るタイピング練習アプリ**

速さ（WPM）だけでなく、1文字ごとの打鍵の間隔（IKI: inter-key interval）や、bigram・trigram ごとの得意・不得意を記録して分析できます。ブラウザだけで動き、記録は自分のブラウザの中に保存されます。

▶ **https://kgnwsknt-chef.github.io/Typattern/**

---

## 主な機能

### タイピング画面
- 英文のお題（約100語）を打つ。URL の末尾に `?short` を付けると、試し打ち用の短いお題（約90文字）になる
- 打っている途中も、平均 IKI・WPM・正確率・ミスを表示
- 打ち終わると結果を表示
  - **キーごとの間隔**：お題の1文字ごとの打鍵間隔の棒グラフ（速いほど青、遅いほど赤）
  - **ランキング**：今回の順位と Top 30
- Backspace で修正できる。Esc でやり直し
- 画面右上でキー配列を選ぶ（今は QWERTY のみ）

### 記録ページ（「記録を見る」）
- 言語・配列・モード・期間（年月日）で記録を絞り込む
- **成績の推移**：平均 IKI（左軸 ms・右軸 打/s）と正確率のグラフ。1回ごと（移動平均つき）または日ごと
- **ランキング**：絞り込んだ記録の Top 30
- **全記録の n-gram**：bigram・trigram ごとの IKI の平均・標準偏差・回数。行をクリックすると分布のヒストグラムを表示

## 指標

| 指標 | 意味 |
| --- | --- |
| 平均 IKI（主な指標） | 1文字あたりにかかった時間（ms）。経過時間 ÷（お題の文字数 − 1）。ミスを直した時間も含む |
| WPM | 1分あたりの語数（1語 = 5文字）。平均 IKI の横に括弧で表示 |
| 正確率 | 最後にお題と合っていた文字の割合。直したミスは含めない |
| ミス | 打った瞬間に間違っていた回数（直したものも数える） |

ランキングは平均 IKI の小さい順で、正確率 95% 未満の回は対象外です。詳しい決まりは [docs/scoring.md](docs/scoring.md) を参照してください。

## 記録の保存について

- 記録は**このブラウザの中だけ**（IndexedDB）に保存され、どこにも送信されません。
- ブラウザや端末が違うと、記録は別々になります。ローカル（`localhost`）と公開サイトの記録も別です。
- ブラウザの閲覧データを消すと記録も消えます。画面右上の「**記録を書き出す**」で JSON ファイルにバックアップし、「**記録を読み込む**」で戻せます。

保存形式は [docs/storage.md](docs/storage.md) を参照してください。

## ローカルで動かす

HTML / CSS / JavaScript だけで、ビルドは不要です。ただし、お題をファイルから読み込むため、`index.html` を直接開くと動きません。付属の簡易サーバー経由で開いてください（Windows）。

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/serve.ps1
```

起動したら http://localhost:8000 を開きます。

## ファイル構成

```
index.html        タイピング画面
stats.html        記録ページ
style.css         見た目
js/app.js         入力・計測・結果の表示・記録の組み立て
js/store.js       記録の保存（IndexedDB）・ランキングの取り出し・書き出し／読み込み
js/rhythm.js      キーごとの間隔のグラフ
js/ranking.js     ランキングの表
js/ngram.js       bigram・trigram の集計と表・分布
js/trend.js       成績の推移のグラフ
js/stats.js       記録ページの処理
texts/            お題（1お題1ファイルの .txt と、一覧の index.json）
docs/             採点ルール・保存形式の説明
```

## お題を追加する

1. `texts/en/` に `題材名.txt`（約100語）と `題材名_short.txt`（約90文字）を置く。1行70文字前後で改行してよい（読み込み時に1行にまとめられる）
2. `texts/index.json` の `"en"` に題材名を足す
