# Typattern (タイパターン)

**打ち方のパターンを見るタイピング練習アプリ**

1打ごとの打鍵の間隔（IKI: inter-key interval）や、続けて押したキーの組（bigram・trigram）ごとの得意・不得意を記録して分析できます。ブラウザだけで動き、記録は自分のブラウザの中に保存されます。詳細は [docs/measurement.md](docs/measurement.md) を参照。

▶ **https://kgnwsknt-chef.github.io/Typattern/**
- 画面上部の「言語」で、英語と日本語を選べる
- 画面上部の「モード」で、文章（約300文字）・短い文章（約90文字）・単語（基本的な単語1000語からランダムに約300文字。英語・日本語とも、単語の間はスペースを打つ）を選べる
- **パソコンのキーボードで使う前提です。スマホ・タブレットには対応していません。**
- **キーの同時押しには対応していません。** 2つ以上のキーを同時に押して1文字を出すかな配列（同時押しのシフト）は使えません。キーはすべて1つずつ順に押したものとして判定・記録し、n-gram でも順に押したキーの組として数えます（Shift を押しながら打った文字は、n-gram の集計から除きます）。
- 日本語の場合、速さは「かな/分」、平均 IKI は1キーストロークあたりの時間で表示します。
- 日本語は、ローマ字のほか、ページの一番上の「キー配列」のページで登録したかな配列でも打てる。割り当て表を読み込み、配列図と試し打ちで確かめてから保存する（[docs/layouts.md](docs/layouts.md)）

## 使い方

1. 上の URL を**パソコンのブラウザ**で開き、表示されたお題をそのまま打ちます。最初のキーを押した瞬間から計測し、最後の文字まで打つと結果が出ます。間違えたら Backspace で直せます。
2. **Esc** でもう一度（同じお題）、**Shift + Enter** で次のお題。打ち始めてから 60 秒キーを押さないと停止します（その回は記録しません）。
3. **日本語**は、画面上部の「言語」で選び、読み（ひらがな）をローマ字で打ちます。**IME（日本語入力）はオフ**にしてください。ローマ字は**いろいろな打ち方に対応**しています（例：「し」は `si`・`shi`・`ci`、「ちゃ」は `cha`・`tya`・`cya`、「ん」は `nn`・`xn`（次が母音・な行・や行でなければ `n` 1つでも可）、「っ」は `xtu`・`ltu` や次の子音を重ねる `kka` など）。お題の上の手引きは、打ち方に合わせて変わります。くわしい決まりは [docs/measurement.md](docs/measurement.md) の「日本語」。
4. 結果の **平均 IKI** は1打あたりの時間（ms）で、小さいほど速い値です。「キーごとの間隔」のグラフで、どの文字（キー）で遅くなったかが分かります。
5. ページの一番上のリンクから、「記録」（レベル・推移・ランキング）、「n-gram」（続けて押したキーの組ごとの速さ）、「キー配列」（かな配列の登録）、「設定」（グラフの範囲・記録の書き出しと読み込みなど）に移れます。

同じ説明は、タイピング画面の「はじめての方へ（使い方）」を開くと読めます。

## 記録の保存について

- 記録は**このブラウザの中だけ**（IndexedDB）に保存され、どこにも送信されません。
- ブラウザや端末が違うと、記録は別々になります。ローカル（`localhost`）と公開サイトの記録も別です。
- ブラウザの閲覧データを消すと記録も消えます。設定のページの「**記録を書き出す**」で JSON ファイルにバックアップし、「**記録を読み込む**」で戻せます。

保存形式は [docs/storage.md](docs/storage.md) を参照してください。

## お題を追加する

英語：
1. `texts/en/` に `題材名.txt`（約300文字）と `題材名_short.txt`（約90文字）を置く。1行70文字前後で改行してよい（読み込み時に1行にまとめられる）
2. `texts/index.json` の `"en"` に題材名を足す

日本語：
1. `texts/ja/` に `題材名.txt`（読みが約300かな）と `題材名_short.txt`（約90かな）を置く。「表示する文」と「読み（ひらがな）」を1行ずつ交互に書く。記号は「、」「。」「ー」だけにする

   ```
   クマムシは、体長が一ミリにも満たない小さな生き物です。
   くまむしは、たいちょうがいちみりにもみたないちいさないきものです。
   ```

2. `texts/index.json` の `"ja"` に題材名を足す

## 単語リストを追加する

1. `wordlists/en/`（英語）か `wordlists/ja/`（日本語）に `リスト名.txt` を置く（1行1語。`#` で始まる行は説明として読み飛ばされる。日本語は「表示する語<タブ>読み（ひらがな）」、かなだけの語は1列でもよい）
2. `wordlists/index.json` の `"en"` か `"ja"` にリスト名を足す
