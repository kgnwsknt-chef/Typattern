# Typattern

**打ち方のパターンを見るタイピング練習アプリ**

速さ（WPM）だけでなく、1打ごとの打鍵の間隔（IKI: inter-key interval）や、続けて押したキーの組（bigram・trigram）ごとの得意・不得意を記録して分析できます。ブラウザだけで動き、記録は自分のブラウザの中に保存されます。詳細は [docs/measurement.md](docs/measurement.md) を参照。

▶ **https://kgnwsknt-chef.github.io/Typattern/**
- 画面上部の「言語」で、英語と日本語を選べる
- 画面上部の「モード」で、文章（約300文字）・短い文章（約90文字）・単語（基本的な英単語1000語からランダムに約300文字。英語のみ）を選べる
- **パソコンのキーボードで使う前提です。スマホ・タブレットには対応していません。**
- 日本語の場合、速さは「かな/分」、平均 IKI は1キーあたりの時間で表示します。
- 日本語は、ローマ字のほか、ページ下部の「キー配列」で登録したかな配列（月見草配列など）でも打てる。割り当て表を読み込み、配列図と試し打ちで確かめてから保存する（[docs/layouts.md](docs/layouts.md)）

## 記録の保存について

- 記録は**このブラウザの中だけ**（IndexedDB）に保存され、どこにも送信されません。
- ブラウザや端末が違うと、記録は別々になります。ローカル（`localhost`）と公開サイトの記録も別です。
- ブラウザの閲覧データを消すと記録も消えます。各ページ下部の「**記録を書き出す**」で JSON ファイルにバックアップし、「**記録を読み込む**」で戻せます。

保存形式は [docs/storage.md](docs/storage.md) を参照してください。

## お題を追加する

英語：
1. `texts/en/` に `題材名.txt`（約300文字）と `題材名_short.txt`（約90文字）を置く。1行70文字前後で改行してよい（読み込み時に1行にまとめられる）
2. `texts/index.json` の `"en"` に題材名を足す

日本語：
1. `texts/ja/` に `題材名.txt`（読みが約300かな）と `題材名_short.txt`（約90かな）を置く。「表示する文」と「読み（ひらがな）」を1行ずつ交互に書く。記号は「、」「。」「ー」だけにする

   ```
   クマムシは、体長が一ミリにも満たない小さな生き物です。
   くまむしは、たいちょうがいちみりにもみたないちいさないきものです。
   ```

2. `texts/index.json` の `"ja"` に題材名を足す

## 単語リストを追加する

1. `wordlists/en/` に `リスト名.txt` を置く（1行1語。`#` で始まる行は説明として読み飛ばされる）
2. `wordlists/index.json` の `"en"` にリスト名を足す
