# Typattern (タイパターン)

▶ **https://kgnwsknt-chef.github.io/Typattern/**

**ブラウザで動く、打ち方のパターンを見るタイピング練習アプリ**

## できること

- **タイピング**：英語と日本語のお題を、文章・単語のモードで打つ。自分の文章や単語リストも追加できる。
- **ノーミス連続タイプ**：ミスなしでどこまで続けて打てるかに挑戦する。
- **練習モード**：苦手な単語、ほかの言語・配列では速い bigram、IKI 測定、キー配列習得（新しい配列の割り当てを覚える）。
- **記録**：レベルの達成度、成績の推移、ランキング。
- **分析**：キー・bigram・trigram ごとの IKI、ミスタイプ（押し間違いやすいキーと並び）、苦手な単語。
- **キー配列**：QWERTY のほか、登録したかな配列・英語の配列で打てる。

### 補足

- **IKI**：1打ごとの打鍵の間隔（inter-key interval）。続けて押したキーの組（bigram・trigram）ごとに集計して、得意・不得意を見る。詳細は [docs/measurement.md](docs/measurement.md)。
- **キー配列の登録**：「設定」のページから開く「キー配列」のページで、割り当て表を読み込み、配列図と試し打ちで確かめてから保存する。英語の配列（Dvorak など）は、英語と日本語のローマ字で使える。詳細は [docs/layouts.md](docs/layouts.md)。
- **キーの同時押し**：2つ以上のキーを同時に押して1文字を出すかな配列でも打てる。IKI のページの bigram・trigram では、同時押しの組を1打として数える。キー配列習得には使えない。

## 記録の保存について

- 記録は自分のブラウザの中（IndexedDB）に保存され、どこにも送信されない。
- ブラウザの閲覧データを消すと記録も消える。設定のページの「**記録を書き出す**」で JSON ファイルにバックアップし、「**記録を読み込む**」で戻せる。

保存形式は [docs/storage.md](docs/storage.md) を参照。
