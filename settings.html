タイピング 記録 n-gram キー配列 設定

設定

変えるとすぐこのブラウザに保存し、ほかのページを開いたとき（開き直したとき）から使います。記録の書き出しには含めません。

グラフ

ms

結果画面と記録のページの「キーごとの間隔」で、棒の一番上にあたる間隔。これを超える間隔は頭打ちにします。

ms

n-gram のページで行をクリックしたときに出す IKI の分布。横軸は 0 からこの値までで、100 個の区間に分けます（区間の幅 = この値 ÷ 100）。これ以上の値は一番右の区間に入れます。

ランキング

% 以上

正確率がこれ未満の回はランキングに載せません（記録は残ります）。推移のグラフの ○（対象外）・移動平均・赤い点線にも使います。レベルの基準（正確率 95% 以上）は変わりません。

タイピング

タイピング中に目標との差を示すインジケーター。まだできていないので、今は設定を保存するだけです。初期値は ON。

データ

保存データ

このブラウザに保存している記録と、登録したキー配列の大きさ（書き出すファイルとほぼ同じ）。

書き出すと、全部の記録と登録したキー配列を1つの JSON ファイルに保存します。読み込むと、そのファイルの記録とキー配列を今のものに足します（同じ記録は飛ばします）。この設定は書き出しに含めません。
